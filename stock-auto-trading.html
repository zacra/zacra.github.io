파이썬 주식·ETF 자동매매 구조

주식·ETF 자동매매는 증권사 Open API를 통해 계좌와 시장을 연결하고, 전략이 계산한 목표상태와 실제 계좌상태의 차이를 주문으로 보정하는 구조로 생각하면 이해하기 쉽습니다.

국내 7개 증권사 API

전략 코드와 증권사 코드를 분리합니다

전략이 증권사의 원본 응답형식을 직접 알게 만들기보다, 각 증권사 Adapter가 잔고·현재가·보유종목·주문을 공통 형태로 변환하도록 설계하면 같은 전략을 여러 증권사에 적용하기 쉬워집니다.

공통모듈은 필요한 기능을 공통화한 실전용 레이어입니다

게만아의 증권사 공통모듈은 각 증권사 API 전체를 똑같이 복제하는 것이 목적이 아닙니다. 실제 전략에서 반복해서 사용하는 인증, 잔고, 보유종목, 시세, 주문 등의 기능을 공통 형태로 만들어 전략 코드가 증권사별 차이를 덜 신경 쓰도록 하는 구조입니다.

Starter는 이 구조의 입문용 최소 범위이며, 정식 모듈은 실제 전략 운용에 필요한 함수가 더 많이 구현되어 있습니다. 그래도 개인적으로 필요한 기능이 빠져 있다면 공식 API 문서를 기준으로 AI와 함께 추가할 수 있습니다.
