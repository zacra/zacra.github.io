Python 자동매매 백테스트 체크리스트

백테스트는 “수익률 그래프 만들기”가 아니라 전략 규칙을 과거 데이터에 동일하게 적용했을 때 어떤 위험과 손익 특성이 나타났는지 확인하는 과정입니다.

최소한 확인할 8가지

  1. 미래정보 참조(Look-ahead bias) — 오늘 알 수 없는 종가·지표를 오늘 주문에 사용하지 않았는지.
  2. 수수료와 거래비용 — 매수·매도 수수료, 세금, 환전, 슬리피지를 전략 특성에 맞게 반영했는지.
  3. 데이터 품질 — 수정주가, 상장·상폐, 결측치와 거래정지 처리를 확인했는지.
  4. 리밸런싱 시점 — 월말 계산 후 다음 거래일 주문처럼 현실적인 시차를 반영했는지.
  5. 체결 가능성 — 거래량이 작은 종목에서 백테스트 가격 그대로 체결된다고 가정하지 않았는지.
  6. MDD — 최종수익률만 보지 말고 중간에 견뎌야 할 최대 낙폭을 확인했는지.
  7. 기간 분할 — 특정 상승장 하나에서만 좋은 전략은 아닌지.
  8. 과최적화 — 파라미터를 조금만 바꿔도 결과가 무너지는지.

실제 자동매매와 백테스트가 다른 이유

실전에서는 API 지연, 주문 거부, 미체결, 거래소 구분, 장 운영시간, 세금과 수수료, 데이터 갱신 시점 등이 개입합니다. 따라서 백테스트가 좋았다는 이유만으로 바로 큰 금액을 투입하기보다 모의투자 또는 소액으로 실전 차이를 확인하는 과정이 필요합니다.

백테스트는 증거이지 보증이 아닙니다

좋은 백테스트는 “이 규칙이 과거의 여러 시장에서 어떻게 행동했는가”를 보여주는 자료입니다. 미래의 동일한 성과를 보장하지 않습니다.
