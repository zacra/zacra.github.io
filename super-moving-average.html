자주 묻는 질문

초보자도 할 수 있나요?

Python 설치와 증권사 API 연결 같은 기본 과정은 직접 진행해야 하지만, 단계별 세팅 가이드와 공식 카페가 있어 순서대로 따라가면 됩니다. 설치 따라하기도 참고하세요.

AWS 서버가 꼭 필요한가요?

아닙니다. GMA Runner로 Windows·Mac PC에서 하루 한 번 자동 실행할 수 있습니다. 실행 시각에 PC가 켜져 있어야 하며, PC를 켜 두기 어렵다면 AWS + crontab을 쓸 수 있습니다.

DB증권이 아니어도 되나요?

기본 자동매매 코드는 DB증권 API 기준입니다. 다른 증권사는 게만아 패키지의 해당 증권사 공통모듈로 전환해 사용할 수 있습니다.

종목과 비중은 누가 정하나요?

포트폴리오(종목 구성)와 투자 금액은 이용자가 직접 정합니다. 개인별 종목 추천은 하지 않으며, 나머지 비중 계산과 추세 판단은 전략의 기본 규칙에 따라 작동합니다.

최근 상장한 ETF도 넣을 수 있나요?

상장한 지 석 달 정도 지난 ETF부터 넣을 수 있습니다. 다만 백테스트 기간에 반영되는 부분이 짧으니 결과 해석에 유의하세요.
