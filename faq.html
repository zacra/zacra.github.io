파이썬 자동매매·증권사 API·코인 API FAQ

주식·ETF·코인 자동매매를 처음 시작할 때 자주 나오는 질문을 짧고 직접적으로 정리했습니다.

파이썬 자동매매는 무엇부터 시작해야 하나요?

전략 규칙을 정하고 과거 데이터로 백테스트한 뒤, API의 조회 기능부터 연결하세요. 실제 주문은 마지막 단계로 미루는 편이 안전합니다. 전체 시작 순서 →

게만아는 주식 자동매매만 다루나요?

아닙니다. 국내·미국주식·ETF, 코인 현물·선물, 백테스트, 자산배분, 증권사·거래소 API를 함께 다룹니다.

어떤 증권사 Open API를 다루나요?

현재 한국투자증권, LS증권, 키움증권, 토스증권, KB증권, NH투자증권, DB증권의 공개 Open API를 다룹니다. 숫자보다 중요한 것은 지원사가 늘어나도 전략 로직을 재사용하기 쉬운 멀티브로커 구조입니다. 멀티 증권사 API 보기 →

코인도 파이썬 자동매매가 가능한가요?

가능합니다. 업비트·빗썸·코인원·바이낸스를 다루며, 거래소별 API 특성에 맞는 공통모듈 → 거래소 API 연결 구조를 사용합니다.

AI로 자동매매 코드를 만들면 패키지가 필요 없지 않나요?

AI는 코드를 빠르게 만들지만 실제 계좌 운용에는 인증·주문·체결·예외처리·서버·백테스트가 함께 필요합니다. 이미 사용해온 코드를 출발점으로 AI와 수정·확장하면 맨땅에서 시행착오를 반복하는 시간을 줄일 수 있습니다. 전체 코드 AI 확장 가이드 →

공식 가이드인데 왜 완성형 코드는 모두 공개하지 않나요?

이 사이트는 투자 철학, 구조, API 비교, 보안, 백테스트와 구현 경험을 공개합니다. 완성형 모듈과 핵심 유료 전략의 전체 소스는 별도 콘텐츠로 구분합니다. 공개 범위 보기 →

왜 수익률보다 MDD를 먼저 보나요?

높은 수익률도 중간 하락폭을 버티지 못하면 실제 복리로 이어지기 어렵기 때문입니다. 투자 철학 자세히 보기 →

백테스트가 좋으면 실전에서도 같은가요?

아닙니다. 수수료, 세금, 슬리피지, 미체결, 주문 지연, API 오류와 시장 변화가 실전 결과에 영향을 줍니다.

효율적 투자선 비중이 미래 최적 비중인가요?

아닙니다. 과거 데이터 기반의 후보입니다. 기간과 제약조건을 바꾸면 결과가 달라질 수 있습니다.

주식과 코인이 같은 API 구조인가요?

기본 철학은 전략과 API 연결을 분리한다는 점에서 같지만 구현은 다릅니다. 주식은 멀티브로커 전환 구조를 활용하고, 코인은 거래소별 공통모듈을 각각 연결합니다. 구조 차이 보기 →

공통모듈에 모든 API 함수가 들어 있나요?

증권사가 제공하는 모든 API를 구현한 범용 SDK는 아닙니다. 대신 패키지와 슈퍼 이동평균 전략을 실제로 운용하는 데 필요한 핵심 기능은 구현되어 있어 일반 사용자가 공식 API 문서를 보고 추가 개발할 필요는 없습니다. 개인적으로 새로운 기능이 필요할 때만 공식 문서와 기존 코드 구조를 바탕으로 AI와 함께 확장할 수 있습니다.

API 키는 어떻게 보관해야 하나요?

API 키·Secret·접근토큰은 비밀번호와 같은 민감한 정보입니다. 다른 사람에게 보이거나 공개적으로 노출되지 않게 주의하고, 노출됐다면 폐기·재발급하는 것이 안전합니다.

게만아가 유사투자자문업자라면 개별 투자상담도 해주나요?

아닙니다. 자밥스튜디오(게만아)는 유사투자자문업자로 신고·운영 중이지만 개별 종목 추천·매매지시·1:1 투자상담·계좌 또는 자금 운용을 제공하지 않습니다. 제공하는 것은 파이썬 코드와 시스템 구축 지식이며, 실제 투자에 적용할 종목·비중·실행 여부는 사용자가 직접 결정합니다. 카페에서도 코드·세팅·API 같은 기술적인 질문을 중심으로 안내합니다. 운영 원칙 자세히 보기 →
