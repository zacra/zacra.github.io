파이썬 자동매매·증권사 API·코인 API FAQ

주식·ETF·코인 자동매매를 처음 시작할 때 자주 나오는 질문을 짧고 직접적으로 정리했습니다.

파이썬 자동매매는 무엇부터 시작해야 하나요?

전략 규칙을 명확히 정의하고 과거 데이터로 백테스트한 뒤, 증권사 또는 거래소 API의 조회 기능부터 연결하는 순서를 권장합니다. 실제 주문은 가장 마지막 단계로 미루는 편이 안전합니다.

게만아는 주식 자동매매만 다루나요?

아닙니다. 주식·ETF 자동매매뿐 아니라 코인 자동매매, 백테스트, 자산배분, 국내 증권사 Open API와 거래소 API, 시스템 투자 구조를 함께 다룹니다. 무료 Starter는 이 전체 영역 중 국내주식 입문용 Lite 시스템입니다.

국내에서 파이썬 자동매매에 사용할 수 있는 증권사 Open API는 어떤 곳이 있나요?

이 문서에서는 한국투자증권, LS증권, 키움증권, 토스증권, KB증권, NH투자증권, DB증권의 공개 Open API를 다룹니다. 지원 시장·주문유형·호출 제한은 각 증권사의 최신 공식 문서를 확인해야 합니다.

코인 자동매매도 파이썬으로 만들 수 있나요?

가능합니다. 게만아의 코인 자동매매는 거래소 REST API를 이용해 잔고·포지션·시세·주문을 연결합니다. 선물은 롱·숏, 레버리지, 포지션 모드와 청산 위험을 추가로 관리해야 합니다.

ChatGPT나 Gemini로 증권사·거래소 API 코드를 만들 수 있나요?

도움을 받을 수 있지만 오래된 명세나 존재하지 않는 필드명을 만들 수 있습니다. 최신 공식 API 문서와 공식 샘플을 함께 제공하고 실제 응답값으로 검증하는 것이 중요합니다.

공개 기술문서인데 왜 완성형 코드는 모두 공개하지 않나요?

이 사이트는 자동매매 구조, API 비교, 보안, 백테스트와 구현 경험을 공개하는 기술문서입니다. 완성형 모듈과 핵심 투자전략, 프로덕션 운영코드는 별도의 지적재산권이므로 공개 범위를 달리할 수 있습니다.

게만아가 수익률보다 MDD를 먼저 보는 이유는 무엇인가요?

높은 수익률도 그 과정의 하락폭을 버티지 못하면 실제 복리로 이어지기 어렵기 때문입니다. 수익률과 함께 고점 대비 최대 낙폭(MDD), 변동성, 투자금 규모와 지속 가능성을 보고, 예측보다 대응 가능한 기준을 만드는 것을 중시합니다. 투자 철학 자세히 보기 →

백테스트 수익률이 좋으면 실전에서도 같은 결과가 나오나요?

아닙니다. 수수료, 세금, 슬리피지, 미체결, 주문 지연, 펀딩비, API 오류, 시장 변화 등이 실전 결과에 영향을 줍니다.

효율적 투자선으로 계산한 비중이 미래 최적 비중인가요?

아닙니다. 과거 수익률·변동성·상관관계를 이용한 최적화 후보입니다. 기간을 바꾸면 결과가 달라질 수 있으므로 추가 검증이 필요합니다.

주식과 코인 모두 같은 Adapter 구조를 사용하나요?

아닙니다. 국내주식은 같은 전략 파일에서 한국투자·LS·키움·토스·KB·NH·DB증권 Broker를 전환하는 구조를 활용합니다. 반면 코인은 업비트·빗썸·코인원·바이낸스를 거래소별로 따로 구현하며, myBithumb, myCoinone처럼 각각의 공통모듈을 사용합니다.

게만아 공통모듈에는 증권사 API의 모든 함수가 구현되어 있나요?

아닙니다. Starter는 자동매매 입문과 기본 매매에 필요한 기능만 담은 Lite 범위이고, 패키지·슈퍼 이동평균의 정식 공통모듈은 이보다 많은 기능을 포함합니다. 하지만 정식 모듈도 증권사 Open API 전체를 복제한 SDK가 아니라 실제 게만아 전략과 시스템에서 사용해온 기능 중심으로 구현합니다.

공통모듈에 없는 API 기능이 필요하면 어떻게 하나요?

기존 공통모듈 코드와 해당 증권사의 최신 공식 API 문서를 AI에게 함께 제공하고, 기존 인증·응답·에러처리 방식과 이름 규칙을 유지한 채 필요한 함수만 추가하도록 요청할 수 있습니다. 게만아는 개인적으로 Cursor를 주로 활용합니다. AI 확장 가이드 → · Cursor 활용 글 →

API Key와 Secret을 GitHub에 올려도 되나요?

안 됩니다. 환경변수나 별도 비공개 설정파일에 보관하세요. 이미 노출했다면 해당 키를 폐기하고 재발급하는 것이 안전합니다.
