현재 지원하는 코인 거래소

코인 자동매매도 주식과 같은 비중으로 다룹니다. 현재 업비트, 빗썸, 코인원, 바이낸스를 다루며, 거래소별 API 특성에 맞춰 현물·선물 자동매매 시스템을 구성합니다. 핵심은 특정 거래소 하나에 묶이는 것이 아니라 전략·봇과 API 연결부를 분리해 재사용하고 확장하기 쉬운 구조를 만드는 것입니다.

처음이라면 자주 묻는 질문부터 확인해보세요

코딩을 잘해야 하는지, 주식만 다루는지, 코인도 가능한지, API 문서를 직접 공부해야 하는지처럼 처음 시작할 때 많이 묻는 내용을 짧게 정리했습니다.

게만아는 주식 자동매매만 다루나요?

아닙니다. 국내·미국주식·ETF뿐 아니라 업비트·빗썸·코인원·바이낸스를 활용한 코인 자동매매도 함께 다룹니다.

코딩 초보자도 시작할 수 있나요?

처음부터 전체 코드를 이해하거나 API 문서를 공부할 필요는 없습니다. 무료 Starter 또는 콘텐츠별 가이드를 따라 전체 흐름부터 경험하고, 필요한 부분을 하나씩 익히는 방식을 권합니다.

증권사·거래소 API 기능을 직접 구현해야 하나요?

일반적인 패키지·슈퍼 이동평균 운용에 필요한 핵심 기능은 이미 구현되어 있습니다. 개인적으로 새로운 기능이 필요할 때만 기존 코드와 공식 문서를 바탕으로 AI와 함께 확장하면 됩니다.

구매 전에 먼저 경험해볼 수 있나요?

네. 무료 Starter로 전략 → 백테스트 → API → 주문까지의 전체 흐름을 먼저 경험할 수 있습니다.

대신 투자해주는 서비스가 아닙니다

게만아 콘텐츠는 사용자가 직접 코드를 확인하고, 자신의 환경에 설치·설정한 뒤 스스로 실행하는 파이썬 교육 콘텐츠입니다. 자밥스튜디오(게만아)는 유사투자자문업자로 신고·운영 중이지만, 개별 종목 추천·1:1 투자상담·계좌 및 자금 운용은 제공하지 않습니다.

자동매매를 블랙박스에 맡기기보다 내가 코드를 갖고, 내가 조건과 비중·실행 여부를 통제하는 구조를 지향합니다. 신고 및 운영 원칙 자세히 보기 →
