국내 7개 증권사 Open API

한국투자증권, LS증권, 키움증권, 토스증권, KB증권, NH투자증권, DB증권을 파이썬 자동매매 개발 관점에서 정리합니다. 단순 공식문서 요약보다 같은 기능을 여러 증권사에 구현할 때 생기는 구조적 차이와 주의점을 계속 보강하는 것이 목표입니다.

처음 파이썬 주식 자동매매를 직접 경험해보고 싶다면

무료 AutobotEx Starter에서는 국내 7개 증권사 중 한 곳을 선택해 투자비중 분석 → 백테스트 → 증권사 Open API 연결 → 실제 계좌 리밸런싱 → 주문 구조까지 직접 확인할 수 있습니다.

Starter는 게만아 전체 콘텐츠의 범위를 뜻하는 것이 아니라 국내주식 자동매매 입문용 공개 Lite 시스템입니다.

문서 원칙

  • 특정 수익을 약속하기보다 전략을 어떻게 검증하고 시스템으로 연결하는지를 설명합니다.
  • 증권사·거래소 API 사양은 가능한 한 최신 공식 문서를 우선합니다.
  • 백테스트는 미래 성과 보장이 아니라 과거 규칙 검증으로 해석합니다.
  • 실제 주문 전에는 주문 비활성화, 모의투자 또는 소액 검증을 권장합니다.
  • API Key·Secret·접근토큰은 공개 저장소에 올리지 않습니다.
