게만아 주식 코드의 특색 — 전략은 그대로, 증권사·시장·계좌만 선택

공통 인터페이스로 작성된 주식 봇은 증권사가 바뀔 때 전략 로직 전체를 다시 만드는 방식이 아닙니다. Broker, Market, accountMode를 선택하면 그에 맞는 Common·API Helper를 동적으로 불러오도록 설계되어 있습니다.

Broker = "KIS"       # KIS / DBI / LS / KIW / TOSS / KB / NH
Market = "KR"        # KR / US
accountMode = "REAL" # REAL / REAL2 / VIRTUAL 등

Common = importlib.import_module(f"{Broker}_Common")
Helper = importlib.import_module(f"{Broker}_API_Helper_{Market}")
Common.SetChangeMode(accountMode)

전략 쪽에서는 GetBalance(), GetCurrentPrice(), MakeBuyMarketOrder() 같은 공통 호출 형식을 사용하므로, 증권사 차이는 공통모듈이 흡수합니다. 지원 시장·계좌·세부 기능은 각 증권사 API 범위에 따라 다릅니다.

문서 원칙

  • 특정 수익을 약속하기보다 전략을 어떻게 검증하고 시스템으로 연결하는지를 설명합니다.
  • 증권사·거래소 API 사양은 가능한 한 최신 공식 문서를 우선합니다.
  • 백테스트는 미래 성과 보장이 아니라 과거 규칙 검증으로 해석합니다.
  • 실제 주문 전에는 주문 비활성화, 모의투자 또는 소액 검증을 권장합니다.
  • API Key·Secret·접근토큰은 공개 저장소에 올리지 않습니다.
