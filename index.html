게만아 시스템 투자 공식 가이드

파이썬으로 만드는 주식·코인 자동매매 시스템

게만아(퀀트는 게만아)가 실제 자금을 파이썬 자동매매 시스템으로 운용하면서 정리한 공식 가이드 허브입니다. 파이썬 자동매매가 처음이라면 복잡한 설명부터 읽기보다 무료 Starter로 전략 → 백테스트 → API 연결 → 실제 자동매매 흐름을 먼저 직접 경험해보세요.

🎁 무료 Starter로 먼저 체험

무료 Starter는 게만아 자동매매 구조를 가장 가볍게 경험해보는 시작점입니다. 직접 확인해본 뒤 아래에서 투자 철학과 다음 선택지를 천천히 살펴보셔도 됩니다.

처음 보는 분을 위한 시작 가이드

이미지와 실제 예시로 먼저 이해하고 싶다면

코드를 바로 체험하기보다 전체 흐름을 먼저 천천히 보고 싶다면 네이버 시작 가이드를 참고하셔도 좋습니다. 이미지와 실제 예시를 중심으로 게만아의 파이썬 자동매매와 시스템 투자 구조를 설명합니다.

어디서 시작하면 될까요?

처음부터 모든 것을 알아야 할 필요는 없습니다. 현재 목적에 가장 가까운 한 가지부터 선택하면 됩니다.

2. 슈퍼 이동평균 자산배분
