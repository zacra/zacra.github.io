서버가 부담스러운 파이썬 자동매매의 새로운 시작점

GMA Runner — Windows·Mac PC에서 파이썬 자동매매 실행·스케줄링

GMA Runner V1은 사용자가 선택한 Python 파일을 내 로컬 컴퓨터에서 실행하고, 반복 일정을 관리하고, 실행 결과와 로그를 웹 화면에서 확인하게 해 주는 공통 실행 도구입니다. 이제 자동매매를 시작한다고 해서 처음부터 AWS 서버를 반드시 만들 필요는 없습니다.

한 줄 요약

파일 준비 → 수동 실행 → 자동 실행 → 로그 확인을 Windows·Mac의 한 화면에서 관리합니다.

왜 만들었나?

게만아의 파이썬 자동매매 코드는 한 번 실행되어 현재 조건을 확인하고 필요한 매매·작업을 수행한 뒤 종료되는 구조를 많이 사용합니다. 그래서 정해진 시간마다 코드를 다시 실행해주는 스케줄러가 중요합니다.

그동안 24시간 완전 자동화를 위해 AWS + crontab을 많이 활용했지만, 월 1회·하루 1회 실행하는 전략이나 실행 시간 동안 PC를 확실히 켜둘 수 있는 사용자까지 처음부터 서버를 만들어야 할 이유는 없습니다. 이 허들을 낮추기 위해 GMA Runner를 만들었습니다.

GMA Runner에서 할 수 있는 것

Python 파일 직접 실행

Workspace에 준비한 Python 파일을 한 번 수동 실행해 결과부터 확인할 수 있습니다. 백테스트 코드도 일반 Python 파일처럼 실행할 수 있습니다.

다양한 자동 실행 일정

N분마다 · 매일 · 매주 · 요일/시간 범위 · 매월 · Crontab 한 줄 가져오기 방식으로 자동 실행을 설정할 수 있습니다.

로그와 상태 확인

SUCCESS·FAILED·TIMEOUT·SKIPPED 같은 실행 상태와 stdout/stderr 로그를 확인해 오류 원인을 찾기 쉽게 합니다.

Windows·Mac 지원

Windows와 macOS에서 같은 로컬 웹 UI를 사용합니다. 브라우저 화면은 외부 웹서비스가 아니라 내 컴퓨터 안에서 열립니다.

“서버가 필요 없다”의 정확한 의미

자동매매를 시작하기 위해 AWS 서버가 필수는 아닙니다. GMA Runner가 실행 중이고 내 PC가 깨어 있다면 정해진 시간에 Python 파일을 실행할 수 있습니다.

다만 Runner는 클라우드 서비스가 아닙니다. 컴퓨터가 꺼지거나 절전되면 새 예약 실행은 시작되지 않고, 재부팅 후에는 Launcher를 다시 실행해야 합니다. 24시간 완전 자동화, 고정 IP, PC 상태와 무관한 운영이 중요하면 AWS 같은 서버 환경이 더 안정적입니다.

초보자 기준 사용 흐름

  1. Python 3.11 이상과 코드 편집 환경을 준비합니다.
  2. Windows 또는 Mac의 GMA Runner Launcher를 실행합니다.
  3. 사용할 Python·YAML·JSON·보조모듈을 Workspace에 직접 준비합니다.
  4. 먼저 Python 파일을 수동 실행해 로그와 결과를 확인합니다.
  5. 정상 동작을 확인한 뒤 원하는 자동 실행 일정을 등록합니다.
  6. 실행 결과·오류가 생기면 로그를 확인하고 필요한 경우 AI나 카페 Q&A를 활용합니다.

Runner가 필요한 파일을 임의로 추론하거나 자동 복사하지는 않습니다. 사용자가 선택한 파일만 다루기 때문에 전략에 필요한 YAML·JSON·공통모듈 등이 있다면 직접 함께 준비해야 합니다.

로컬 전용 관리 화면

GMA Runner의 웹 UI는 기본적으로 127.0.0.1에만 열립니다. 외부 인터넷에서 로그인해 사용하는 SaaS 서비스가 아니라 내 컴퓨터 안에서 실행되는 로컬 관리 화면입니다.

Runner는 전략의 의미를 판단하거나 코드를 임의로 수정하지 않습니다. API Key 사용, 주문 실행, 파일 변경, 네트워크 요청 등은 사용자가 선택한 전략 코드가 수행하는 동작이므로 실제 주문 전에는 설정을 직접 확인해야 합니다.

패키지·슈퍼 이동평균 이용자에게 함께 제공합니다

GMA Runner는 현재 별도 상품으로 판매하지 않고 게만아 패키지와 슈퍼 이동평균 자산배분 이용자에게 함께 제공합니다. 기존 이용자도 제공되는 Google Drive에서 받을 수 있습니다.

자주 묻는 질문

GMA Runner를 쓰면 AWS 서버가 필요 없나요?

시작부터 AWS가 필수는 아닙니다. 내 PC가 켜져 있고 Runner가 실행 중이면 자동 실행할 수 있습니다. 다만 24시간 안정 운용이나 고정 IP가 중요하면 AWS 같은 서버가 더 적합할 수 있습니다.

브라우저를 닫으면 자동 실행도 멈추나요?

브라우저만 닫는 것은 괜찮습니다. 하지만 Runner Launcher 창이 살아 있고 컴퓨터가 깨어 있어야 예약 실행이 계속됩니다.

컴퓨터를 재부팅하면 자동으로 다시 시작하나요?

현재 V1은 운영체제 부팅 시 자동 시작을 등록하지 않습니다. 재부팅 후 Launcher를 다시 실행해야 합니다.

게만아 코드만 실행할 수 있나요?

아닙니다. 사용자가 선택한 일반 Python 파일을 실행하고 예약하는 공통 실행 도구입니다. 다만 파일 역할과 의존성은 자동 추론하지 않습니다.

GMA Runner 안에서 코드를 수정하나요?

현재 웹 화면은 전략 원본 편집기가 아닙니다. VS Code 같은 편집기에서 원본을 수정한 뒤 Workspace에 다시 가져와 덮어쓰는 흐름을 권장합니다.

핵심은 선택지가 생겼다는 것입니다

게만아 파이썬 자동매매 → AWS → crontab뿐 아니라, 이제는 게만아 파이썬 자동매매 → Windows/Mac → GMA Runner라는 루트도 있습니다.

내 전략의 실행 시간 동안 PC를 켜둘 수 있다면 GMA Runner만으로 시작해도 됩니다. 더 높은 안정성이 필요해지는 시점에 서버로 넘어가도 늦지 않습니다.
