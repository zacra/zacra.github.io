핵심은 세 가지입니다

FAST · SLOW 더블 이동평균

최근 500일(FAST)과 1800일(SLOW) 구간에서 각각 가장 잘 맞았던 이동평균 조합으로, 비중을 반반 나눠 보유·현금을 판단합니다.

하락 추세 대응 게이트

하락 추세를 걸러 내 하락장에서 계좌가 크게 망가지는 것을 줄입니다. 구체적인 조건은 구매 후 제공되는 코드에서 확인합니다.

동일 비중 · 현금 관리

투자할 코인은 직접 고르고, 선정한 코인은 동일 비중으로 운용합니다. 조건이 맞지 않는 몫은 현금으로 둡니다.

검증 방식

Rolling / Walk-Forward 백테스트로 과거 각 시점에서 그때까지의 데이터만 사용해 FAST·SLOW 조합을 다시 구하고, 거래 비용을 반영해 동일 비중 단순보유와 비교합니다.

자주 묻는 질문

이 전략만 따로 살 수 있나요?

네. 20만원 단독 상품으로 이용할 수 있고, 게만아 패키지(500,000원) 102번에도 포함돼 있습니다. 코인 장기투자만 한다면 패키지를 살 필요가 없습니다.

초보자도 가능한가요?

Python 환경 설정과 거래소 API 연결은 직접 진행해야 하지만, 단계별 세팅 가이드와 공식 카페가 있어 순서대로 따라가면 됩니다.

거래소 3곳을 모두 써야 하나요?

아닙니다. 업비트·빗썸·코인원 중 쓰는 거래소만 설정하면 됩니다. 투자할 코인은 직접 고르고, 선정한 코인은 동일 비중으로 운용됩니다(코인별 비중을 따로 정하지 않습니다).

AWS 서버가 꼭 필요한가요?

아닙니다. GMA Runner로 Windows·Mac에서 하루 한 번 자동 실행할 수 있습니다. 실행 시각에 PC가 켜져 있어야 하며, PC를 켜 두기 어렵다면 AWS + crontab을 쓸 수 있습니다.

얼마나 자주 실행하나요?

이동평균 조합을 만드는 MakeFindMa_Coin.py는 한 달에 한 번 정도, 자동매매 봇은 하루 한 번(종가 근방 권장) 실행합니다.

수익률은 어느 정도인가요?

투자 대상·시장 상황·설정에 따라 달라지며 특정 수익률을 보장하지 않습니다. 공식 포스팅의 과거 백테스트 결과와 MDD를 함께 참고하세요.
