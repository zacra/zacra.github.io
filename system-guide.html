게만아 파이썬 자동매매 시작 가이드

투자 목적에 따라 두 가지로 시작하세요

게만아 자동매매의 핵심은 누군가가 계좌를 대신 운용하는 것이 아니라, 투자자가 직접 이해하고 통제하는 시스템 투자 구조를 만드는 것입니다.

먼저 철학부터

수익률보다 MDD · 감정보다 기준 · 예측보다 대응.

더 많은 정보를 찾기보다 판단을 줄이고, 미리 정한 전략과 원칙을 시스템이 반복 실행하도록 만드는 것이 게만아 자동매매의 출발점입니다.

1. 다양한 주식·코인 자동매매를 원한다면 — 게만아 패키지

한국·미국 주식과 ETF, 코인까지 다양한 전략 중에서 자신의 투자 성향에 맞는 시스템을 선택하고 확장하고 싶은 분을 위한 코드·가이드 묶음입니다.

  • 주식·ETF 자산배분 전략
  • 코인 자동매매 전략
  • 추세·역추세·분할매매·리밸런싱 구조
  • 백테스트와 서버 자동 실행
  • 증권사·거래소 연동 모듈 및 세팅 가이드
  • 한 번 받은 코드를 직접 보유하고 AI와 함께 수정·확장

패키지는 하나의 전략이 아니라 90개 이상의 전략·시스템 코드에서 필요한 것을 선택해 사용하는 ‘무기창고’에 가깝습니다.

2. 주식·ETF 장기투자 하나에 집중한다면 — 슈퍼 이동평균 자산배분

여러 전략을 직접 비교하기보다, 장기 주식·ETF 투자 시스템 하나에 집중하고 싶은 분을 위한 게만아의 대표 전략입니다.

  • 이동평균 기반 추세 판단
  • 비중 조절과 리밸런싱
  • 조건에 따른 현금 비중 확보
  • MDD와 투자 지속력 관리
  • 백테스트 → 포트폴리오 설정 → 자동매매까지 연결

기본 제공은 DB증권 API 기반이며, 다른 증권사 환경으로의 확장은 별도 패키지의 해당 증권사 공통모듈을 활용하는 방식입니다.
