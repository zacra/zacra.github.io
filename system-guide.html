게만아 파이썬 자동매매 시작 안내

세팅이 복잡해 보여도, 처음부터 다 알 필요는 없습니다

Python, 서버, API 같은 단어를 한꺼번에 보면 어렵게 느껴질 수 있습니다. 하지만 실제로는 자신에게 맞는 콘텐츠를 하나 선택하고 → 제공되는 가이드를 순서대로 따라가며 → 작은 규모로 실행을 확인하면 됩니다. 코딩 경험이 많지 않아도 각 단계를 하나씩 진행할 수 있도록 필요한 코드와 안내를 함께 제공합니다.

먼저 세팅 방법보다 “무엇으로 시작할지”만 고르세요

자동매매를 시작하기 전에 AWS나 API 문서를 공부할 필요는 없습니다. 내가 어떤 방식의 투자를 자동화하고 싶은지를 먼저 정하면 됩니다. 실제 세팅은 그 다음 단계입니다.

1. 다양한 주식·코인 전략을 골라 활용하고 싶다면 — 게만아 패키지

한국주식·미국주식·ETF·코인까지 여러 전략과 시스템 코드를 직접 받아 활용하고, 필요하면 AI와 함께 수정·확장하고 싶은 분에게 맞습니다.

  • 현재 97개 전략·시스템 콘텐츠에서 필요한 것을 선택
  • 자산배분·추세추종·분할매매·레버리지 ETF·코인 현물·선물 등 다양한 구조
  • 백테스트 코드와 실제 자동매매 봇을 함께 활용
  • 증권사·거래소 연동에 필요한 공통 구조와 보조시스템 포함
  • 받은 소스 코드를 직접 확인하고 AI와 함께 변경·확장 가능

여러 방법론을 코드로 비교하고 자신에게 맞는 시스템을 만들어가는 ‘무기창고’에 가까운 콘텐츠입니다.

패키지 자세히 보기 계좌이체 구매 (교차구매 시 5만원 할인) 카드·간편결제 (정상가)

2. 주식·ETF 장기투자 시스템 하나에 집중한다면 — 슈퍼 이동평균 자산배분

많은 전략을 직접 고르기보다 추세 판단·비중 조절·리밸런싱·현금 비중 관리를 하나의 장기 투자 시스템으로 운용하고 싶은 분에게 맞습니다.

  • 이동평균을 중심으로 한 추세 판단과 자산배분
  • 시장 상황에 따른 투자 비중 조절과 리밸런싱
  • 현금 비중을 활용한 MDD 관리
  • 백테스트 → 포트폴리오 설정 → 실제 자동매매까지 연결
  • DB증권 지원 코드는 슈퍼 이동평균 전략에 포함

슈퍼 이동평균 자세히 보기 계좌이체 구매 (교차구매 시 5만원 할인) 카드·간편결제 (정상가)

아직 유료 콘텐츠를 결정하기 어렵다면 — 무료 Starter

자동매매가 어떤 방식으로 이어지는지 먼저 경험해보고 싶다면 무료 Starter부터 시작해도 됩니다. 투자전략 → 비중 분석 → 백테스트 → Open API 연결 → 실제 주문 구조의 흐름을 직접 확인할 수 있습니다.

세팅 때문에 구매를 망설일 필요가 없는 이유

  • 처음부터 모든 기술을 공부하는 구조가 아닙니다. 필요한 순서대로 하나씩 따라가면 됩니다.
  • 실전 운용에 필요한 핵심 API 기능은 이미 코드에 구현되어 있습니다. 증권사 API 문서를 처음부터 읽고 직접 기능을 만드는 것이 기본 과정이 아닙니다.
  • 서버와 자동 실행 환경은 한 번 세팅해두면 반복해서 처음부터 만들 필요가 없습니다.
  • 구매한 콘텐츠에는 관련 설명과 세팅 가이드가 연결되어 있어 코드만 던져드리는 방식이 아닙니다.
  • 추가 아이디어가 생기면 전략·백테스트·자동매매 봇·공통모듈·보조시스템까지 AI와 함께 수정·확장할 수 있습니다.

처음 화면만 보면 어려워 보일 수 있지만, 실제로는 한 단계 완료 → 다음 단계 진행의 반복입니다.

패키지와 슈퍼 이동평균을 모두 이용한다면

어느 것을 먼저 구매해도 두 번째 콘텐츠를 구글폼 계좌이체로 구매할 때 5만원 할인이 적용됩니다. 카드·간편결제는 정상가 결제 경로입니다.

구매 후 실제 세팅은 대략 이런 흐름입니다

아래 용어를 지금 외울 필요는 없습니다. 전체 과정을 미리 보고 싶은 분만 펼쳐보세요. 실제 진행 때는 각 콘텐츠에서 연결되는 세팅 안내를 보며 순서대로 따라가면 됩니다.

자동매매 세팅 8단계 전체 흐름 보기 — 처음에는 펼치지 않아도 됩니다
단계무엇을 하나요?쉽게 말하면
1. 개발환경Python · Visual Studio Code 설치코드를 열고 실행할 준비
2. 서버AWS EC2 등 실행 환경 준비내 PC를 꺼도 봇이 돌아갈 공간
3. 고정 IP필요한 경우 탄력적 IP 연결API에서 허용할 서버 주소 고정
4. 파일 준비전략·공통모듈 등을 서버에 업로드실행할 코드를 서버에 넣기
5. API 연결증권사·거래소에서 발급받은 API 정보 적용내 계좌와 코드 연결
6. 실행 테스트잔고·시세·전략 설정·주문 안전장치 확인실전 전에 제대로 연결됐는지 점검
7. 자동 실행crontab 등으로 실행 시간 등록정해진 시간에 봇이 스스로 실행
8. 알림·운영필요하면 메시지 알림을 연결하고 상태 확인주문·오류 등을 편하게 확인

처음부터 하지 않아도 되는 것들

  • 증권사 API 문서 전체 공부: 자동매매에 필요한 모든 기능을 직접 구현할 필요는 없습니다.
  • 여러 전략 동시 세팅: 처음에는 전략 하나만 정상 실행해보면 충분합니다.
  • 여러 증권사 동시 연결: 내가 사용할 증권사 하나부터 시작하면 됩니다.
  • 메시지 서비스 여러 개 연결: 알림은 필요할 때 나중에 추가해도 됩니다.
  • 코드 전체 이해: 처음에는 설정값과 실행 흐름을 익히고, 필요할 때 조금씩 코드 이해 범위를 넓혀도 됩니다.

상세 세팅 자료는 필요한 시점에 확인하면 됩니다

Python 설치, 서버 생성, 파일 업로드, API 연결, 자동 실행처럼 화면을 보며 따라가야 하는 내용은 실제 콘텐츠 이용 시 연결되는 단계별 가이드에서 확인할 수 있습니다. AWS나 증권사 화면은 시간이 지나며 바뀔 수 있기 때문에 실제 세팅 시점의 안내를 기준으로 따라가는 것이 가장 편합니다.

즉, 구매 전에 복잡한 세팅 문서를 미리 공부할 필요는 없습니다. 먼저 어떤 투자 시스템을 사용할지 결정하고, 세팅은 그 다음에 하나씩 진행하면 됩니다.

실전 전에는 이것만 꼭 확인하세요

  • 투자 비중: 처음에는 낮은 비중으로 충분히 테스트합니다.
  • 주문 실행 여부: 실제 주문을 켜기 전에 주문 안전장치와 설정값을 직접 확인합니다.
  • 종목·코인과 비중: 자신의 전략에 맞게 설정됐는지 확인합니다.

백테스트와 실제 주문 환경은 수수료·체결·데이터·계좌 상태 등에서 차이가 날 수 있으므로 처음에는 조회와 소액 테스트부터 단계적으로 진행하는 것이 좋습니다.
