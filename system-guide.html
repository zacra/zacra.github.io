게만아 파이썬 자동매매 시작 가이드

처음부터 실제 자동 실행까지, 전체 흐름을 먼저 이해하세요

게만아 자동매매의 핵심은 누군가가 계좌를 대신 운용하는 것이 아니라, 투자자가 직접 이해하고 통제하는 시스템 투자 구조를 만드는 것입니다. Python 설치부터 서버·API·백테스트·자동 실행까지 큰 흐름을 먼저 잡으면 개별 전략을 세팅하기가 훨씬 쉬워집니다.

먼저 방향만 이해하세요 — 예측보다 대응

게만아 시스템 투자는 미래를 정확히 맞히기보다 규칙을 정하고 백테스트한 뒤, 시장이 움직이면 그 기준대로 대응하는 것을 중요하게 봅니다. 추세추종을 핵심 축으로 활용하지만 이동평균 하나에만 의존하지 않고 다양한 지표와 전략을 검증해 사용할 수 있습니다. 투자 철학 자세히 보기 →

자동매매 세팅은 이 순서로 진행합니다

단계무엇을 하나요?핵심
1. 개발환경Python · Visual Studio Code 설치코드를 열고 수정·백테스트할 기본 환경
2. AWS 서버AWS 계정 생성 · EC2 인스턴스 준비내 PC를 꺼도 24시간 실행되는 자동매매 환경
3. 고정 IP탄력적 IP 생성 및 EC2 연결거래소·증권사 API의 허용 IP 등록에 활용
4. 파일 업로드SFTP/FileZilla 등으로 서버 연결봇·공통모듈을 /var/autobot 등에 업로드
5. 자동 실행crontab 등록원하는 시간·주기마다 파이썬 봇을 자동 실행
6. API 연결증권사·거래소 API Key 발급 및 적용잔고·시세·주문 기능을 실제 계좌와 연결
7. 메시지텔레그램·슬랙·디스코드·카카오톡 등 연동봇 실행·주문·오류 상태를 메시지로 확인
8. 전략 실행전략 이해 → 백테스트 → 비중 설정 → 실행 테스트처음에는 낮은 비중과 주문 안전장치부터 확인

주식은 한 증권사에 묶이지 않도록 설계합니다

게만아의 공통 인터페이스 기반 주식 봇은 Broker · Market · accountMode를 분리해, 같은 전략 로직을 여러 증권사·국내/미국 시장·여러 계좌에 재사용하기 쉽게 구성합니다.

현재 한국투자·LS·키움·토스·KB·NH·DB증권 환경을 다루며, 지원사가 늘어나더라도 전략 파일 전체를 다시 만드는 것보다 공통모듈을 확장하는 방향을 지향합니다.

처음 세팅한다면 — 스크린샷 가이드를 그대로 따라가세요

Python·Visual Studio Code 설치부터 AWS 계정, EC2 서버, 탄력적 IP, SFTP/FileZilla, crontab, 파이썬 모듈 설치까지는 실제 화면을 보면서 진행하는 것이 가장 빠릅니다.

게만아의 상세 가이드에는 각 단계의 스크린샷과 실제 입력 예시가 정리되어 있습니다. AWS 화면이나 설치 UI는 시간이 지나며 바뀔 수 있으므로, 이 문서에서는 전체 구조를 설명하고 실제 클릭 과정은 네이버 블로그 상세 가이드에서 계속 업데이트합니다.

게만아 환경에서는 서버 준비를 더 단순화할 수 있습니다

게만아 세팅 가이드에서는 AWS EC2 생성 시 GMA_AutobotServer로 검색되는 AMI를 활용하는 방법을 안내합니다. 해당 AMI에는 자동매매용 기본 폴더와 crontab 등 일부 서버 세팅을 미리 준비해 두어 처음부터 모든 명령어를 직접 구성하는 부담을 줄이는 방식입니다.

서버 환경이나 AWS 정책은 바뀔 수 있으므로 실제 생성 시점의 안내는 위 스크린샷 가이드를 기준으로 확인하세요.

메시지 연동은 별도 상세 가이드가 있습니다

자동매매는 주문만 실행되는 것보다 봇이 실행됐는지, 매수·매도가 발생했는지, 오류가 있었는지를 메시지로 확인할 수 있어야 운영이 편합니다.

기존 LINE Notify 종료 이후 게만아 가이드에서는 텔레그램 · 슬랙 · 디스코드 · 카카오톡 연동 방법과 telegram_alert.py, slack_alert.py, discord_alert.py, kakao_alert.py, All_alert.py 활용 구조를 설명합니다.

환경 구축이 끝났다면 전략 하나만 선택하세요

처음부터 여러 전략을 동시에 세팅할 필요는 없습니다. 전략 하나를 선택 → 관련 가이드 확인 → 필요 API 발급 → 공통모듈 준비 → 백테스트 → 서버 실행 테스트 → crontab 등록 순으로 한 사이클을 완성해 보는 것이 좋습니다.

게만아 패키지 코드 상단에는 해당 전략의 설명·세팅 포스팅을 연결해 두었으므로, 먼저 코드 상단 주석과 관련 가이드를 확인하세요.

패키지 실전 세팅 전체 가이드 →

1. 다양한 주식·코인 자동매매를 원한다면 — 게만아 패키지

한국주식·미국주식·ETF·코인까지 다양한 전략 중에서 자신의 투자 성향에 맞는 시스템을 선택하고 확장하고 싶은 분을 위한 코드·가이드 묶음입니다.

  • 주식·ETF 자산배분과 추세추종 전략
  • 코인 현물·선물 자동매매 전략
  • 떨사오팔(평균회귀·역추세) 등 분할매매 구조
  • TQQQ·SOXL 같은 미국 레버리지 ETF 분할매수 아이디어의 시스템화·변형 코드
  • 백테스트와 서버 자동 실행
  • 증권사·거래소 연동 모듈 및 세팅 가이드
  • 한 번 받은 코드를 직접 보유하고 AI와 함께 수정·확장

게만아가 개인적으로 추세추종과 MDD 관리를 더 선호한다고 해서 역추세·레버리지 전략을 배제하는 것은 아닙니다. 패키지는 여러 방법론을 실제 코드로 비교하고 자신에게 맞게 디벨롭할 수 있는 연구용 무기창고라는 성격도 있습니다.

패키지는 하나의 전략이 아니라 현재 97개 전략·시스템 콘텐츠에서 필요한 것을 선택해 사용하는 ‘무기창고’에 가깝습니다.

패키지 내용 확인 계좌이체 구매 (교차구매 시 5만원 할인) 카드·간편결제 (정상가)

2. 주식·ETF 장기투자 하나에 집중한다면 — 슈퍼 이동평균 자산배분

여러 전략을 직접 비교하기보다, 장기 주식·ETF 투자 시스템 하나에 집중하고 싶은 분을 위한 게만아의 대표 전략입니다.

  • 이동평균 기반 추세 판단
  • 비중 조절과 리밸런싱
  • 조건에 따른 현금 비중 확보
  • MDD와 투자 지속력 관리
  • 백테스트 → 포트폴리오 설정 → 자동매매까지 연결

DB증권 지원 코드는 슈퍼 이동평균 자산배분 전략에 포함되어 있으며, 다른 증권사 환경으로 전환할 때는 별도 패키지의 해당 증권사 공통모듈을 활용하는 방식입니다.

슈퍼 이동평균 내용 확인 계좌이체 구매 (교차구매 시 5만원 할인) 카드·간편결제 (정상가)

두 콘텐츠를 모두 구매한다면

패키지와 슈퍼 이동평균 자산배분은 어느 것을 먼저 구매해도 두 번째 콘텐츠 구매 시 5만원 할인이 적용됩니다.

할인은 구글폼을 통한 계좌이체 구매에서 적용됩니다. 이미 한쪽을 구매했다면 다른 쪽을 계좌이체로 구매하면서 정상가에서 5만원을 뺀 금액을 이체하면 됩니다. 카드·간편결제(래피드)는 정상가 결제 경로입니다.

아직 파이썬 자동매매 자체가 낯설다면

유료 콘텐츠를 먼저 결정하지 않아도 됩니다. 현재 지원 중인 증권사 가운데 한 곳을 선택해 투자전략 → 효율적 투자비중 분석 → 백테스트 → Open API 연결 → 실제 계좌 리밸런싱 → 주문 구조까지 체험하는 무료 Starter가 있습니다.

기초부터 차근히 배우고 싶다면

패키지와 슈퍼 이동평균은 제공되는 가이드에 따라 세팅할 수 있도록 구성되어 있지만, Python 자동매매의 원리를 기초부터 이해하고 싶다면 클래스101의 게만아 자동매매 강의를 선택적으로 활용할 수 있습니다.

실전에서는 세 가지를 반드시 확인합니다

  • 투자 비중: 처음에는 낮은 비중으로 충분히 테스트합니다.
  • 주문 실행 여부: ENABLE_ORDER_EXECUTION 같은 안전장치가 있는 코드라면 실제 주문 전 값을 직접 확인합니다.
  • 포트폴리오: 종목·코인 리스트와 비중이 자신의 전략에 맞게 설정됐는지 확인합니다.

백테스트 결과가 좋아도 실제 주문에서는 API 사양, 수수료, 체결, 데이터 지연, 계좌 상태 같은 변수가 추가됩니다. 조회·로그·소액 테스트를 거쳐 단계적으로 실전으로 옮기세요.

실전 결과는 ‘수익 인증’보다 전략의 작동 과정을 봅니다

게만아 투자 실험실에서는 실제 계좌의 수익과 손실, 수익률과 MDD, 전략이 상승장과 하락장을 지나며 어떻게 움직였는지를 기록하고 매월 결산합니다.

주식·연금 계좌는 낮은 변동성으로 큰돈을 오래 운용하는 방향을 지향합니다. 최근 공개된 메인 주식 계좌 종합 기록은 연환산 수익률 약 20%대, MDD 약 -10% 수준이며 연금계좌 역시 같은 위험관리 철학으로 운용합니다. 이 수치는 시간이 지나면서 계속 변경될 수 있습니다.
