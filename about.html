게만아 소개

게만아(퀀트는 게만아)는 주식·ETF·코인 투자전략을 파이썬으로 백테스트하고, 증권사·거래소 API와 연결해 자동매매 시스템으로 구현하는 과정을 다루는 콘텐츠 브랜드입니다.

주요 분야

  • 주식·ETF 파이썬 자동매매
  • 코인 현물·선물 파이썬 자동매매
  • 백테스트와 시스템 트레이딩
  • 국내 증권사 Open API
  • 거래소 API와 주문 자동화
  • 자산배분·효율적 투자선·리밸런싱
  • 여러 증권사·거래소를 공통 구조로 연결하는 자동매매 아키텍처

왜 공개 기술문서를 운영하나요?

자동매매를 처음 공부하면 전략, 데이터, 백테스트, API 인증, 계좌 조회, 주문 코드가 서로 분리되어 있어 전체 구조를 이해하기 어렵습니다. 이 사이트는 특정 매매전략의 전체 소스코드를 공개하는 저장소라기보다, 자동매매 시스템을 이해하고 구현할 때 필요한 기술적 판단 기준을 정리하는 공식 자료실을 목표로 합니다.

무료 Starter와의 관계

무료 AutobotEx Starter는 국내주식 자동매매의 전체 흐름을 실제로 한 번 경험하기 위한 입문용 Lite 시스템입니다. 게만아가 다루는 전체 영역은 국내주식뿐 아니라 ETF, 코인, 백테스트, 자산배분, 여러 증권사·거래소 API로 더 넓습니다.

공식 채널

게만아 네이버 블로그파이썬 자동매매 가이드와 실제 운용 콘텐츠파이썬 자동매매 전체 시작 가이드처음 보는 분을 위한 전체 안내자동매매 구현 사례 및 후기사용자 구현 사례 모음Class101 게만아공개 콘텐츠와 클래스

투자 관련 안내

이 사이트는 교육·기술 정보 제공 목적입니다. 특정 금융상품의 매수·매도를 권유하거나 수익을 보장하지 않습니다. 자동매매 코드와 전략은 오류, 체결조건, 시장 변화 등에 따라 손실이 발생할 수 있으므로 사용자가 직접 검증해야 합니다.
