공식 가이드와 유료 코드의 경계

게만아 공식 가이드는 가능한 한 유용한 개념과 구조를 공개하면서, 완성형 자동매매 시스템과 핵심 전략 소스코드는 별도 콘텐츠로 구분해 운영합니다.

공식 가이드에서 공개하는 것

  • 파이썬 자동매매의 전체 구조와 설계 원칙
  • 증권사·거래소 API 비교와 공식 출처
  • 백테스트 검증 관점과 흔한 오류
  • API 키 보안과 주문 안전장치
  • 멀티 증권사·거래소 연결 구조의 개념
  • 효율적 투자선과 자산배분의 원리
  • 실제 구현 경험에서 얻은 일반적인 주의사항

별도 콘텐츠로 구분하는 것

  • 실전 전략에서 사용하는 완성형 증권사·거래소 공통모듈 소스
  • 유료 투자전략의 핵심 진입·청산 로직
  • 다계좌·미체결·상태관리 등 전체 운영 코드
  • 전략별 전체 소스와 유료 콘텐츠 전용 구현

무료·유료 콘텐츠의 역할

  • 공식 가이드: 개념, 철학, 구조, API 비교, 백테스트와 세팅 방향
  • 무료 Starter: 자동매매 전체 흐름을 실제로 한 번 체험
  • 슈퍼 이동평균: 주식·ETF 장기 자산배분 시스템 하나에 집중
  • 게만아 패키지: 다양한 주식·코인 전략과 공통모듈·자동화 코드 베이스

공통모듈도 공식 API 전체를 복제한 SDK는 아닙니다

목적은 증권사의 모든 엔드포인트를 미리 구현하는 것이 아니라 패키지와 슈퍼 이동평균 전략에서 실제로 필요한 기능을 일관된 형태로 제공하는 것입니다. 정식 콘텐츠 운용에 필요한 핵심 기능은 이미 구현되어 있으며, 개인적으로 그 밖의 API 기능이 필요할 때만 공식 문서와 AI를 이용해 추가할 수 있습니다.

왜 구분하나요?

공식 가이드는 “무엇을 왜 이렇게 설계하는지”를 이해할 수 있게 공개합니다. 유료 코드는 그 구조를 실제 전략과 증권사·거래소 환경에서 활용할 수 있도록 구현해온 코드 자산과 업데이트를 포함합니다.

무료 Starter는 공개 입문 코드입니다

Starter로 전체 흐름을 먼저 확인한 뒤 자신에게 맞는지 판단할 수 있습니다. Starter가 전체 전략·시장·기능을 모두 무료로 제공한다는 의미는 아닙니다.
