공개 기술문서와 유료 코드의 경계

게만아 기술문서는 가능한 한 유용한 정보를 공개하되, 완성형 자동매매 시스템과 핵심 전략 소스코드의 지적재산권은 별도로 보호하는 방향으로 운영합니다.

공개하는 것

  • 파이썬 자동매매의 전체 구조와 설계 원칙
  • 증권사·거래소 API 비교와 공식 출처
  • 백테스트에서 흔히 생기는 오류와 검증 체크리스트
  • API Key 보안과 주문 안전장치
  • 여러 증권사·거래소를 공통 인터페이스로 묶는 개념
  • 효율적 투자선과 자산배분의 원리
  • 실제 구현 경험에서 얻은 비독점적 주의사항·트러블슈팅

공개 범위를 제한할 수 있는 것

  • 완성된 증권사·거래소 Helper/Common 모듈 전체
  • 유료 투자전략의 핵심 진입·청산 로직
  • 다계좌·고급주문·미체결관리·상태관리 등 프로덕션 코드
  • 운영 안정화를 위한 전체 예외처리·재시도·알림 시스템
  • 유료 콘텐츠로 제공하는 전략별 전체 소스

무료·유료 콘텐츠의 역할도 구분합니다

  • GitHub 기술문서: 개념, 철학, 구조, API 비교, 보안과 트러블슈팅
  • 무료 Starter: 국내주식 자동매매 전체 흐름을 실제로 한 번 체험
  • 슈퍼 이동평균: 대표 주식·ETF 장기 자산배분 시스템의 완성형 구현
  • 게만아 패키지: 다양한 주식·코인 전략과 공통모듈·자동화 시스템 코드 베이스

왜 이 방식이 필요한가?

기술문서는 “무엇을 왜 이렇게 설계해야 하는지”를 설명합니다. 유료 코드는 이를 실제 증권사·거래소 환경에서 바로 사용할 수 있도록 구현하고 검증하는 시간과 노하우를 포함합니다. 공개 문서가 유용해야 신뢰할 수 있지만, 모든 구현 자산을 무료로 공개해야 기술문서의 가치가 생기는 것은 아닙니다.

Starter는 공개 입문 제품입니다

무료 AutobotEx Starter는 국내주식 자동매매의 한 흐름을 실제로 경험할 수 있도록 의도적으로 공개한 Lite 시스템입니다. Starter의 존재가 게만아의 모든 전략·시장·기능이 무료 공개된다는 의미는 아닙니다.
