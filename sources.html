새로운 API 기능을 직접 추가할 때는 공식 문서가 기준입니다

게만아 패키지와 슈퍼 이동평균을 일반적으로 운용하기 위해 이 문서들을 처음부터 읽고 API를 구현할 필요는 없습니다. 실제 전략에서 사용하는 핵심 기능은 기존 코드에 구현되어 있습니다.

다만 현재 코드에 없는 조회·주문·상품 기능을 개인적으로 추가할 때는 AI가 추측하게 두기보다 최신 공식 개발자 문서를 함께 제공하세요. 엔드포인트, 요청 필드, 응답 구조와 호출 제한은 공식 문서를 기준으로 검증합니다.
