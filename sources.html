공식 문서는 AI 확장 작업의 기준점입니다

현재 게만아 공통모듈에 없는 함수를 추가할 때는 기존 코드만 보고 AI에게 추측하게 하기보다, 이 페이지의 공식 개발자 문서를 함께 제공하는 것이 중요합니다. 엔드포인트, 요청 필드, 응답 구조, 호출 제한은 공식 문서를 정본으로 두고 기존 공통모듈 스타일에 맞춰 구현합니다.

바이낸스 출처는 CCXT를 기준으로 봅니다

게만아의 myBinance는 CCXT를 이용해 Binance에 연결하므로, 사이트에서는 Binance 직접 API 문서보다 CCXT 공식 문서를 코드 구현의 주요 출처로 연결합니다. 실제 Binance 기능이 CCXT에서 어떻게 노출되는지는 CCXT 문서와 현재 라이브러리 버전을 함께 확인합니다.
