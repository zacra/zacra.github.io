게만아 핵심 투자 개념

시스템 투자를 이해하기 위한 핵심 개념 모음

게만아의 콘텐츠는 특정 종목을 맞히는 방법보다 투자 규칙을 만들고, 위험을 측정하고, 백테스트로 검증하고, 필요하면 파이썬으로 반복 실행하는 구조에 초점을 둡니다. 아래 개념을 순서대로 보면 전체 흐름을 훨씬 쉽게 이해할 수 있습니다.

처음이라면 이 세 개부터 보세요

1. 시스템 투자

감정에 따라 매번 판단을 바꾸기보다 투자 조건과 위험관리 기준을 규칙으로 만드는 상위 개념입니다.

2. MDD

최종 수익률만으로 보이지 않는 고점 대비 최대 손실을 측정합니다. 실제로 전략을 유지할 수 있는지를 생각할 때 중요한 숫자입니다.

MDD란? →

3. 추세추종

미래를 맞히기보다 현재 확인된 방향에 대응하는 대표적인 규칙 기반 접근입니다.

백테스트

과거 데이터에서 규칙을 적용해 수익률뿐 아니라 MDD, 비용, 과최적화, 기간 민감도와 실전 차이를 확인합니다.

백테스트 체크리스트 →

효율적 투자선

여러 자산의 비중을 바꿨을 때 위험과 기대수익이 어떻게 달라지는지 이해하는 대표적인 자산배분 개념입니다.

투자 철학

수익률보다 MDD, 감정보다 기준, 예측보다 대응이라는 게만아의 시스템 투자 관점을 한 페이지에 정리했습니다.

시스템 투자가 판단 기준을 만드는 일이라면 파이썬 자동매매는 전략 → 데이터 → 백테스트 → API → 주문 → 기록을 코드로 연결해 같은 기준을 반복 실행하는 방법입니다.

목적별로 골라 읽기

위험과 손실부터 이해하고 싶다면MDD와 회복률, 위험관리 예측보다 대응하는 방법이 궁금하다면추세추종과 휩쏘, 현금 비중 전략을 어떻게 검증하는지 궁금하다면과최적화·미래참조·실전 차이 여러 자산의 비중을 정하는 방법이 궁금하다면효율적 투자선과 포트폴리오 실제 자동화 구조가 궁금하다면파이썬·API·주문·서버 자동화

한 문장으로 연결하면

시스템 투자로 기준을 만들고 → MDD로 위험을 보고 → 추세추종·자산배분 같은 규칙을 선택하고 → 백테스트로 검증한 뒤 → 필요하면 파이썬 자동매매로 반복 실행합니다.
