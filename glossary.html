자동매매 용어, 쉽게 풀어드립니다

MDD, 백테스트, API 같은 말이 낯설어도 괜찮습니다. 자주 나오는 용어를 ‘쉽게 말하면’ 한 줄과 짧은 설명으로 정리했습니다. 본문에서 모르는 말을 만나면 이 페이지로 돌아와 찾아보세요.

처음이라면 이 순서로 읽어보세요. 자동매매 → 백테스트 → MDD → API → GMA Runner. 이 다섯 가지만 알아도 사이트의 대부분을 이해할 수 있습니다.

시작 개념

자동매매

내가 정해둔 규칙대로 컴퓨터가 대신 주문을 내는 것

‘언제, 무엇을, 얼마나 살지’를 미리 정해두면 프로그램이 그 규칙을 반복 실행합니다. 누군가에게 돈을 맡기는 것이 아니라 내 규칙을 내 계좌에서 실행하는 방식입니다. 더 알아보기 →

파이썬(Python)

자동매매 프로그램을 쓰는 데 가장 많이 쓰이는 프로그래밍 언어

문법이 비교적 쉬워 데이터 분석·백테스트·주문 코드를 한 언어로 다룰 수 있습니다.

시스템 투자

그날 기분이 아니라 정해둔 기준으로 투자하는 방식

매수·매도·비중 조절 기준을 미리 글로 정해 두고 그대로 따릅니다. 자동매매는 이 기준을 컴퓨터가 반복 실행하는 것입니다. 더 알아보기 →

API / Open API

내 프로그램이 증권사·거래소와 대화하는 통로

프로그램이 잔고 조회, 현재가 조회, 주문 같은 일을 요청할 수 있게 증권사가 열어 둔 공식 창구입니다. 증권사 앱 대신 프로그램이 쓰는 앱이라고 생각하면 쉽습니다. 더 알아보기 →

API Key / Secret

API에 접속하기 위한 비밀번호 같은 값

다른 사람에게 보이면 안 됩니다. 공개된 곳에 올리지 말고, 노출됐다면 폐기하고 다시 발급받으세요.

공통모듈

증권사마다 다른 API를 같은 방식으로 쓰게 해주는 변환 코드

증권사마다 주문 방법이 달라도 전략 코드는 그대로 두고 연결 부분만 바꾸기 쉽게 만든 구조입니다. 더 알아보기 →

투자·위험 개념

백테스트

내 전략을 과거 데이터에 돌려 보는 연습 경기

과거에 이 규칙으로 투자했다면 어땠는지 계산해 봅니다. 과거 결과가 좋았다고 앞으로도 같다는 뜻은 아닙니다. 더 알아보기 →

과최적화

과거에만 딱 맞게 끼워 맞춘 전략

시험 문제 답을 외워서 점수만 높은 상태와 비슷합니다. 백테스트는 좋은데 실전에서 무너지는 대표적인 원인입니다. 더 알아보기 →

MDD(최대낙폭)

가장 높은 곳에서 가장 낮은 곳까지 얼마나 떨어졌는지

예를 들어 MDD가 -20%라면 최고점에서 최저점까지 20% 하락한 적이 있다는 뜻입니다. 수익률만큼, 혹은 그보다 먼저 확인해야 하는 ‘버틸 수 있는 하락폭’의 기준입니다. 더 알아보기 →

추세추종

오르는 중이면 따라가고, 꺾이면 물러나는 방식

가격을 미리 맞히려 하지 않고 이미 나타난 흐름에 반응합니다. ‘예측보다 대응’과 같은 말입니다. 더 알아보기 →

이동평균

최근 가격의 평균을 이은 선

추세를 부드럽게 보여주는 가장 기본적인 지표입니다. 가격이 이동평균 위에 있는지 아래에 있는지로 흐름을 판단하는 데 자주 씁니다. 더 알아보기 →

자산배분

한 곳에 몰지 않고 여러 자산에 나눠 담는 것

주식·채권·금처럼 성격이 다른 자산을 나눠 담아 한쪽이 흔들릴 때 전체 충격을 줄이려는 방법입니다. 더 알아보기 →

효율적 투자선

같은 위험이라면 기대수익이 가장 높은 조합을 모아둔 선

과거 수익률·변동성·상관관계로 계산하는 비중 ‘후보’입니다. 미래의 정답이 아닙니다. 더 알아보기 →

리밸런싱

정해둔 비중과 달라진 내 계좌를 다시 맞추는 일

목표가 A 50% : B 50%인데 A가 올라 70%가 됐다면 일부를 팔고 B를 사서 다시 맞춥니다.

슬리피지

예상한 가격과 실제 체결된 가격의 차이

주문을 낸 사이에 가격이 움직이거나 호가가 달라서 생깁니다. 백테스트에는 잘 드러나지 않지만 실전에서는 비용이 됩니다.

Rolling / Walk-Forward

‘그 시점에 알 수 있던 데이터’만으로 계속 다시 검증하는 방식

미래 데이터를 미리 보고 만든 전략이 되지 않도록, 과거 시점마다 그 이전 데이터만 사용해 반복 검증합니다. 더 알아보기 →

실행 환경

GMA Runner

내 PC에서 파이썬 파일을 실행·예약하고 로그를 보는 관리 프로그램

서버 없이 Windows·Mac에서 시작할 수 있습니다. PC가 꺼지거나 절전이면 예약 실행이 시작되지 않는 점은 알아두세요. 더 알아보기 →

서버 / AWS

내 PC를 꺼도 프로그램이 계속 돌아가는 원격 컴퓨터

24시간 안정 운용이나 고정 IP가 필요할 때 선택합니다. 처음부터 필수는 아닙니다. 더 알아보기 →

crontab

정해진 시간에 자동으로 프로그램을 실행시키는 서버의 알람

‘평일 오전 9시 5분에 이 파일 실행’처럼 등록해 두면 서버가 그 시간에 맞춰 실행합니다.

로그

프로그램이 무엇을 했는지 남기는 기록

주문이 나갔는지, 오류가 났는지 확인하는 용도입니다. 자동매매는 로그를 확인하는 습관이 중요합니다.
