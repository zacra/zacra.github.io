효율적 투자선(Efficient Frontier)과 Python 자산배분

여러 자산의 비중을 바꾸면 기대수익률과 변동성이 다른 수많은 포트폴리오가 만들어집니다. 그중 위험 대비 효율적인 조합의 경계를 효율적 투자선이라고 부릅니다.

동일비중에서 시작하면 이해가 쉽습니다

N개 자산에 똑같이 투자하면 각 자산 비중은 1/N입니다. 단순하고 과최적화 위험이 낮다는 장점이 있지만, 자산별 변동성과 상관관계를 반영하지는 않습니다.

대표적인 후보

Equal Weight

모든 자산을 동일 비중으로 배분합니다. 가장 단순한 기준점입니다.

Minimum Variance

과거 공분산 구조를 기준으로 전체 포트폴리오 변동성을 낮추는 조합을 찾습니다.

Maximum Sharpe

과거 기대수익과 변동성을 이용해 샤프 비율이 높은 조합을 찾습니다.

왜 비중 제한이 필요한가?

제약 없는 최적화는 과거에 좋았던 자산 한두 개에 비중이 과도하게 몰릴 수 있습니다. Starter 예시는 1/N을 기준으로 최소·최대 비중 범위를 두어 극단적인 집중을 완화하는 접근을 사용합니다.

# 개념 예시
base = 1 / N
min_weight = 0.5 * base
max_weight = 2.0 * base

이 범위 자체가 모든 전략에 정답이라는 의미는 아닙니다. 중요한 것은 최적화 결과를 그대로 믿기보다 제약조건과 백테스트를 함께 보는 것입니다.

실전에서 확인할 항목

  • 학습 구간을 조금 바꾸면 비중이 크게 흔들리는가?
  • 특정 자산에 지나치게 집중되는가?
  • 수수료·세금·리밸런싱 빈도를 반영했는가?
  • 동일비중과 비교했을 때 위험 대비 개선이 일관적인가?
  • 미래 데이터가 계산에 섞이지 않았는가?

해석 주의

효율적 투자선은 미래를 알려주는 예측기가 아닙니다. 과거 데이터에 대한 수학적 최적화 결과이므로, 다른 기간에서는 결과가 달라질 수 있습니다.
