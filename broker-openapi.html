게만아 멀티브로커 구조

국내 증권사 Open API 비교와 멀티브로커 자동매매

현재 게만아 자동매매 생태계는 한국투자·LS·키움·토스·KB·NH·DB증권을 다룹니다. 하지만 이 페이지의 핵심은 ‘7개’라는 숫자가 아닙니다. 같은 전략 로직을 증권사마다 다시 만들지 않고, 공통 인터페이스를 통해 여러 증권사·시장·계좌로 옮기기 쉽게 만든 구조가 더 중요한 차별점입니다.

전략은 그대로, Broker · Market · 계좌만 선택

공통 인터페이스로 작성된 게만아 주식 봇에서는 아래와 같이 사용할 증권사, 시장, 계좌 모드를 정하고 그에 맞는 모듈을 동적으로 불러옵니다.

Broker = "KIS"       # KIS / DBI / LS / KIW / TOSS / KB / NH
Market = "KR"        # KR / US
accountMode = "REAL" # REAL / REAL2 / VIRTUAL 등

Common = importlib.import_module(f"{Broker}_Common")
Helper = importlib.import_module(f"{Broker}_API_Helper_{Market}")
Common.SetChangeMode(accountMode)

전략 본문은 이후 Helper.GetBalance(), Helper.GetMyStockList(), Helper.GetCurrentPrice(), Helper.MakeBuyMarketOrder() 같은 공통 호출 형식을 사용합니다. 증권사별 인증 방식·응답 필드·주문 API 차이는 Common/Helper 모듈이 최대한 흡수하고, 전략은 자산 선택·비중·리밸런싱 같은 투자 규칙에 집중합니다.

세 가지 축을 따로 바꿀 수 있습니다

설정역할예시
Broker사용할 증권사 공통모듈 선택KIS, LS, KIW, TOSS, KB, NH, DBI
Market국내주식·미국주식 Helper 선택KR / US
accountMode설정파일에 정의한 실전·추가계좌·모의계좌 선택REAL / REAL2 / VIRTUAL 등

따라서 같은 전략을 국내·미국 시장이나 여러 계좌에서 운용할 때 코드 전체를 복제해 다시 만드는 부담을 줄일 수 있습니다. 단, 각 증권사의 실제 지원 시장·모의투자·주문 유형·계좌 종류는 서로 다르므로 지원 범위 확인은 필요합니다.

현재 다루는 증권사 Open API

증권사공식 개발 환경에서 확인되는 핵심게만아 코드 연결

패키지와 DB증권 범위는 구분합니다

일반 패키지에는 한국투자·LS·키움·토스·KB·NH의 공통모듈이 포함되어 있으며, DB증권 기반 구현은 슈퍼 이동평균 자산배분 콘텐츠 쪽에서 제공됩니다. 따라서 ‘현재 7개 증권사를 다룬다’와 ‘패키지 하나에 7개 공통모듈이 모두 포함된다’는 같은 의미가 아닙니다.

왜 이 구조가 유용한가?

  • 증권사 변경 비용 감소: 전략 규칙은 유지하고 API 레이어만 교체하기 쉽습니다.
  • 계좌 분산: 같은 전략을 여러 계좌로 나눠 운용할 때 설정을 분리하기 쉽습니다.
  • 국내·미국주식 확장: 지원되는 공통모듈에서는 Market 선택으로 KR/US Helper 구조를 재사용할 수 있습니다.
  • 새 증권사 추가: 지원사가 8개, 9개로 늘어나더라도 전략 파일 전체보다 공통모듈 확장에 집중할 수 있습니다.
  • AI 활용: 이미 통일된 함수 규격이 있으므로 새 증권사나 새 기능을 AI와 함께 추가할 때 기준점이 명확합니다.

비교할 때 실제로 봐야 하는 것

  1. 내 계좌·상품 지원: 국내주식, 미국주식, 연금 등 필요한 영역이 실제로 가능한지.
  2. 인증과 토큰: App Key/Secret, OAuth, 토큰 유효기간과 재발급 정책.
  3. 호출 제한: 초당/분당 호출량이 전략 주기에 맞는지.
  4. 전략에 필요한 기능: 잔고·보유종목·현재가·주문 등 실제 필요한 API가 있는지.
  5. 모의투자와 주문유형: 실계좌 전 검증 환경과 시장가·지정가·정정취소 등 필요한 주문을 지원하는지.
  6. 공식 샘플·문서: 최신 문서와 개발지원 자료가 충분한지.

게만아 공통모듈은 ‘증권사 API 전체를 복제한 SDK’가 아닙니다

증권사 Open API에는 매우 많은 기능이 존재하지만, 게만아 공통모듈은 실제 전략과 자동매매 시스템에서 사용하는 기능을 중심으로 구현합니다. Starter는 그중에서도 입문에 필요한 기능만 공개한 Lite 버전입니다.

현재 공통모듈에 없는 기능이 필요하더라도 해당 증권사의 공식 API가 제공한다면 기존 함수 스타일을 기준으로 추가할 수 있습니다.

중요: ‘쉽게 전환’은 공통화된 범위 안에서의 이야기입니다

증권사마다 지원 상품, 시장 코드, 모의투자, 주문유형, 호출 제한이 다릅니다. 따라서 Broker 값 하나만 바꾸면 세상의 모든 API 기능이 완전히 동일하게 동작한다는 의미는 아닙니다. 게만아 코드가 사용하는 공통 기능을 중심으로 차이를 흡수한 구조라고 이해하면 정확합니다.
