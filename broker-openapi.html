2026 국내 7개 증권사 Open API 비교

Python 자동매매를 만들 때 “어느 증권사가 최고인가?”보다 내가 필요한 시장·주문·개발 환경을 공식 API가 지원하는지를 먼저 보는 것이 좋습니다. 아래 내용은 2026-08-21 기준 공식 개발자 문서에서 확인한 범위를 중심으로 정리했습니다.

증권사공식 개발 환경에서 확인되는 핵심자동매매 개발 포인트Starter
한국투자증권REST + WebSocket, 국내·해외주식 등, 공식 Python GitHub공식 샘플과 문서 범위가 넓음선택 가능
LS증권OAuth, REST, 실시간, 국내·해외주식/파생 카테고리TR 기반 기능이 매우 세분화선택 가능
키움증권REST, OAuth, WebSocket, 국내·미국주식멀티 OS + 허용 IP 구조 확인 필요선택 가능
토스증권OAuth 2.0, REST, 국내·미국주식, 조건주문통합된 최신형 API 구조가 특징선택 가능
KB증권Token 기반 인증, 시세·종목·계좌·잔고·주문공식 포털과 GitHub/챗봇 제공선택 가능
NH투자증권REST + WebSocket, 주식·파생·채권·금현물, 공식 SDK/MCP2026년 정식 오픈, AI 개발지원 적극적선택 가능
DB증권OAuth, 국내·해외주식/파생/채권, 실시간, 공식 SDK/MCPPython 샘플과 AI 코딩 지원 제공선택 가능

비교할 때 실제로 봐야 하는 7가지

  1. 내 계좌·상품 지원: 국내주식만 필요한지, 미국주식·파생까지 필요한지.
  2. 운영체제: Windows 전용 요소가 있는지, Linux 서버에서도 REST 호출 가능한지.
  3. 인증: App Key/Secret, OAuth, 토큰 유효기간과 재발급 정책.
  4. 호출 제한: 초당/분당 호출량은 전략 설계에 직접 영향을 줍니다.
  5. 실시간 데이터: WebSocket이 필요한 단타인지, REST만으로 충분한 중장기인지.
  6. 모의투자: 주문 코드를 실계좌 전에 검증할 환경이 있는지.
  7. 공식 샘플·SDK: 문서, GitHub, MCP/AI 개발도구가 얼마나 잘 갖춰져 있는지.

중요: API 사양은 바뀝니다

호출 제한, 주문 유형, 거래소 구분, 인증 유효기간은 증권사 공지에 따라 변경될 수 있습니다. 이 문서는 비교를 위한 출발점이며 실제 구현 전에는 반드시 증권사 공식 문서를 다시 확인하세요.
