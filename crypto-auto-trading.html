파이썬 코인 자동매매 시작 가이드

코인 자동매매는 거래소 API와 24시간 시장이라는 특성 때문에 주식과 공통점도 많고 차이도 큽니다. 게만아의 코인 자동매매는 REST API를 중심으로 잔고·포지션·시세·주문을 연결하며, 현물·선물, 포지션 방향, 레버리지와 주문 상태를 명확히 분리합니다.

1. 현물과 선물을 먼저 구분합니다

현물은 보유 수량과 평균단가 중심으로 생각할 수 있지만, 선물은 롱·숏 포지션, 레버리지, 증거금 방식, 청산 위험, 포지션 모드 같은 추가 상태가 있습니다.

2. REST API 중심으로 조회와 주문을 연결합니다

게만아의 코인 자동매매는 실시간 호가창이나 초단타 처리를 전제로 하지 않고 REST API 중심으로 구성합니다. 잔고, 포지션, 현재가, 과거 캔들, 주문과 설정 정보를 전략 실행 주기에 맞춰 조회하고 처리합니다.

3. 거래소별 차이를 Adapter로 분리합니다

같은 시장가 매수라도 거래소마다 symbol 형식, 수량 단위, 최소주문금액, precision, 선물 포지션 파라미터가 다를 수 있습니다. 전략 코드가 이런 차이를 직접 처리하게 하지 않는 편이 유지보수에 유리합니다.

4. API Key 권한을 최소화합니다

자동매매에 필요한 거래 권한만 부여하고 출금 권한은 가능하면 비활성화합니다. API Key와 Secret은 공개 GitHub, 영상, 로그, 스크린샷에 노출하지 않습니다.

5. 백테스트와 실전의 차이

24시간 시장이라도 API 장애, 서버 재시작, 펀딩비, 거래수수료, 슬리피지, 레버리지, 강제청산, 거래소별 시세차이가 실전 결과에 영향을 줍니다. 선물 전략일수록 실전 검증 단계가 중요합니다.

6. 주문 전 안전장치

  • 실행 플래그 OFF 상태에서 신호와 수량 출력
  • 최소주문금액·수량단위 검사
  • 현재 포지션과 주문 방향 재확인
  • 중복 주문 방지
  • API 오류·시간초과 재시도 정책
  • 실제 운용 전 소액 테스트

공개 범위
