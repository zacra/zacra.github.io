코인 자동매매도 핵심은 예측보다 대응입니다

코인은 24시간 거래되고 변동성이 크기 때문에 자동화의 장점이 큽니다. 하지만 주문을 자동으로 넣는 것보다 먼저, 큰 하락에서 얼마나 위험을 줄일 것인지가 정해져 있어야 합니다. 게만아는 코인에서도 백테스트·MDD·추세추종·비중 관리를 중심으로 시스템을 설계합니다.

지원 거래소

업비트 · 빗썸 · 코인원 · 바이낸스를 다룹니다. 현물뿐 아니라 바이낸스 선물처럼 롱·숏, 레버리지, 포지션 모드가 필요한 구조도 별도로 구현합니다.

1. 주식과 달리 거래소별 공통모듈을 따로 둡니다

코인 거래소마다 인증 방식, 심볼 체계, 최소주문금액, 수량 정밀도, 현물·선물 주문 파라미터가 다릅니다. 그래서 억지로 하나의 Broker 구조에 모두 넣기보다 거래소별 공통모듈과 전략 연결부를 분리해 관리합니다.

업비트 전략/봇   → 공통모듈 → 업비트 API
빗썸 전략/봇     → 공통모듈 → 빗썸 API
코인원 전략/봇   → 공통모듈 → 코인원 API
바이낸스 전략/봇 → 공통모듈 → 바이낸스 API

공통모듈의 실제 파일명은 구현 시점에 따라 달라질 수 있으므로, 여기서는 전략·봇과 거래소 API 사이의 연결 구조 자체를 기준으로 설명합니다.

2. 현물과 선물은 같은 것으로 보면 안 됩니다

현물은 보유 수량과 평균단가가 중심이지만 선물은 롱·숏 포지션, 레버리지, 증거금, 강제청산, 포지션 모드 등 추가 상태를 관리해야 합니다. 특히 선물은 주문 성공 여부뿐 아니라 현재 포지션과 주문 방향을 재확인하는 안전장치가 중요합니다.

3. REST API 중심으로 반복 실행합니다

게만아의 주된 구조는 실시간 호가창 초단타보다 REST API를 이용해 잔고·포지션·현재가·캔들·주문 정보를 전략 실행 주기에 맞춰 확인하고, 조건이 충족되면 주문하는 방식입니다.

전략은 한 번 실행되어 조건을 확인하고 종료되고, 서버의 스케줄러가 정해진 주기로 다시 실행하는 구조를 많이 활용합니다.

4. 코인에서는 특히 추세추종을 더 선호합니다

코인은 큰 상승만큼 큰 하락도 빠르게 발생합니다. 그래서 저는 가격이 떨어질수록 계속 매수하는 구조보다 추세가 무너지면 위험 노출을 줄이고, 흐름이 회복될 때 다시 참여하는 방식을 핵심 철학에 더 가깝게 봅니다.

과거 실제 운용 사례 중에는 비트코인이 전고점 대비 약 절반 수준까지 하락한 구간에서 실계좌 낙폭을 -15% 미만 수준으로 방어한 기록도 공개해왔습니다. 모든 하락을 피했다는 의미가 아니라, 큰 하락에서 계좌 전체의 MDD를 제한하는 시스템이 어떤 역할을 했는지를 보여주는 사례입니다.

이 기록은 특정 과거 구간의 결과이며 미래에도 같은 성과를 보장하지 않습니다.

5. 그렇다고 평균회귀·분할매매를 배제하는 것은 아닙니다

게만아 패키지에는 코인에서도 떨사오팔처럼 하락 시 분할매수하고 반등 시 분할매도하는 평균회귀·역추세 계열을 포함해 여러 전략 아이디어가 코드로 구현되어 있습니다.

다만 강한 하락 추세가 길어지면 추가 매수와 MDD가 커질 수 있으므로, 구현되어 있다는 것과 핵심 장기 철학으로 선호한다는 것은 구분합니다. 패키지는 여러 전략을 직접 백테스트하고 수정·비교할 수 있는 연구용 코드 베이스이기도 합니다.

6. 주문 전 안전장치

  • 실행 플래그 OFF 상태에서 신호와 주문 수량 먼저 확인
  • 최소주문금액·수량단위·precision 검사
  • 현재 보유·포지션과 주문 방향 재확인
  • 중복 주문 방지
  • API 오류·시간초과·재시도 정책
  • 실제 운용 전 소액 테스트

7. API Key는 최소 권한으로 관리합니다

자동매매에 필요한 거래 권한만 부여하고 출금 권한은 가능하면 비활성화합니다. 발급받은 API 키와 Secret은 비밀번호와 같은 정보이므로 다른 사람에게 보이지 않도록 관리하고, 화면 캡처나 공유 과정에서도 노출되지 않게 주의하세요.

코인에서도 자동매매는 ‘예측 엔진’이 아니라 ‘기준 실행기’입니다

미래 가격을 정확히 맞히는 것이 목적이 아닙니다. 전략을 과거 데이터로 검증하고, 손실과 MDD를 감당할 수 있는 비중으로 설정하며, 조건이 바뀌면 미리 정한 규칙대로 대응합니다.

투자 유의사항

이 페이지는 교육·기술 정보 제공을 목적으로 합니다. 특정 코인의 매수·매도 추천이나 수익 보장이 아니며, 백테스트와 실계좌의 과거 기록은 미래 성과를 보장하지 않습니다. 특히 선물·레버리지는 손실과 청산 위험이 크므로 충분한 검증과 위험 관리가 필요합니다.
