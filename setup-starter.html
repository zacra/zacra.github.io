무료 Starter로 Python 설치부터 첫 실행까지

무료 Starter 하나로 Python·VS Code 설치 → 모듈 설치 → 증권사 API 연결 → 내 계좌 조회까지 해봅니다. 실제 주문 코드는 주석으로 막혀 있어 안심하고 실행할 수 있습니다.

끝나면 · 내 PC의 파이썬 코드로 내 증권사 잔고·보유 종목·현재가가 출력됩니다. 서버는 필요 없습니다. 이미 Python과 VS Code가 있다면 4번부터 하면 됩니다.

전체 지도1단계 · 무료 Starter2단계 · GMA Runner3단계 · AWS 서버오류 해결

  1. 무료 Starter 신청하고 받기

    Starter 공개 글의 신청폼에서 사용할 증권사 한 곳을 고르고, 구글 드라이브를 쓸 수 있는 이메일을 적습니다. 승인되면 AutobotEx_Starter_증권사 폴더(예: AutobotEx_Starter_KIS)를 볼 수 있습니다.

    • 열람 권한은 승인일로부터 5일입니다. 그 안에 폴더를 PC에 내려받아 보관하세요. 받은 파일은 계속 쓸 수 있습니다.
    • 1인 1개 증권사 버전입니다. 개인 학습용이며 공유·재배포는 금지입니다.
    • 게만아 패키지가 있다면 패키지 85번에 같은 내용이 있어 따로 신청하지 않아도 됩니다.

    됐는지 확인 · 내 PC에 AutobotEx_Starter_… 폴더가 있고, 안에 …_KR_Test.py와 my…_StockInfo.yaml 파일이 보이면 됩니다.

    더 보기: Starter 소개 · 원본 글 4)

  2. Python 설치 (3.14 권장)

    Python은 파이썬 코드를 실행하는 프로그램입니다. 3.14를 설치하세요. 3.11~3.14도 쓸 수 있지만, 2026년 10월에 나온 3.15는 일부 모듈(ccxt 등)이 아직 지원하지 않아 권장하지 않습니다.

    Windows

    python.org 다운로드 페이지에서 두 방식 중 하나를 고릅니다.

    • A방식 · Python install manager — 설치 중 검은 창에 질문이 나오면 y를 입력합니다. 그다음 시작 메뉴에서 명령 프롬프트를 새로 열고 py install 3.14를 입력하면 3.14가 설치됩니다.
    • B방식 · Python 3.14.x 설치 파일 — 첫 화면에서 Add python.exe to PATH를 꼭 체크합니다. Customize installation을 눌러 체크 박스를 모두 켜고 진행해도 됩니다.

    Mac

    python.org macOS 다운로드에서 Python 3.14의 .pkg 설치 파일을 받아 열고, 안내대로 계속을 눌러 설치합니다.

    됐는지 확인 · 터미널(Windows는 명령 프롬프트)을 새로 열고 아래를 입력합니다. Python 3.14.x처럼 나오면 성공입니다.

    # Windows
py -3 --version
python --version

# Mac
python3 --version

    막히면 · Windows에서 'python'은(는) 내부 또는 외부 명령 … 이 아닙니다가 나오거나 Microsoft Store가 열리면 PATH 문제입니다. → 오류 해결: Python을 찾지 못함

    원본: 더 쉬워진 세팅 1)

  3. VS Code 설치하고 첫 파일 실행해 보기

    VS Code(Visual Studio Code)는 코드를 열고 고치는 편집기입니다. code.visualstudio.com에서 받아 계속 다음을 눌러 설치합니다.

    1. VS Code 왼쪽의 확장(Extensions) 아이콘을 누르고 python을 검색해 Microsoft의 Python 확장을 설치합니다. 이미 설치되어 있으면 Uninstall 버튼이 보이니 그대로 두면 됩니다.
    2. VS Code를 껐다가 다시 켭니다.
    3. 새 파일에 print("파이썬 자동매매 시작!") 한 줄을 쓰고 test.py로 저장합니다(Windows Ctrl+S, Mac Cmd+S).
    4. 오른쪽 아래에 인터프리터를 고르라는 느낌표가 있으면 눌러서 Recommended(추천)가 붙은 Python을 고릅니다.
    5. 상단 메뉴 실행 → 디버깅 없이 실행을 누르고, 디버거 선택 창이 뜨면 Python Debugger를 고릅니다.

    됐는지 확인 · 아래 터미널 창에 파이썬 자동매매 시작!이 출력되면 성공입니다. 이것이 파이썬 코드를 실행하는 기본 동작입니다.

    막히면 · 실행해도 반응이 없거나 「파이썬 확장 로드 중」이 계속되면 → 오류 해결: VS Code에서 실행이 안 됨

  4. Starter 폴더 열고 모듈 설치

    모듈은 파이썬에 기능을 더하는 추가 부품입니다(데이터 처리, 그래프, 시세 수집 등).

    1. VS Code에서 파일 → 폴더 열기(Open Folder)로 받은 Starter 폴더(예: AutobotEx_Starter_KB)를 엽니다. 파일만 따로 열지 말고 폴더를 여세요. 그래야 코드가 같은 폴더의 설정 파일(yaml)을 찾습니다.
    2. 상단 메뉴 터미널 → 새 터미널을 엽니다.
    3. 아래 명령을 그대로 복사해 붙여 넣고 Enter를 누릅니다.
    pip install pandas numpy matplotlib scipy requests pyyaml pytz finance-datareader

    PC에 따라 설치했는데도 실행할 때 ModuleNotFoundError가 나는 경우가 있습니다. 미리 막으려면 아래 줄을 한 줄씩 차례로 실행해 두세요. 이미 설치된 것은 건너뛰고, 없는 명령이라고 나오는 줄은 무시해도 됩니다.

    python -m pip install pandas numpy matplotlib scipy requests pyyaml pytz finance-datareader
pip3 install pandas numpy matplotlib scipy requests pyyaml pytz finance-datareader
python3 -m pip install pandas numpy matplotlib scipy requests pyyaml pytz finance-datareader

    됐는지 확인 · 끝부분에 Successfully installed … 또는 Requirement already satisfied가 나오고 ERROR가 없으면 됩니다.

    막히면 · error: subprocess-exited-with-error처럼 긴 오류가 나면 대개 Python 3.15 때문입니다. → 오류 해결: 모듈 설치가 실패함

    패키지·슈퍼 이동평균은 더 많은 모듈이 필요하지만, GMA Runner의 기본 모듈 설치/복구 버튼으로 한 번에 설치할 수 있습니다(2단계).

  5. 증권사 Open API 신청

    내 계좌를 코드로 조회·주문하려면 증권사에서 Open API를 신청해 앱 키(APP Key)와 앱 시크릿(APP Secret)을 받아야 합니다. 증권사마다 신청 화면이 달라서, 내가 쓰는 증권사 안내 하나만 따라가면 됩니다.

    한국투자증권LS증권키움증권토스증권KB증권NH투자증권DB증권메리츠증권

    각 안내 페이지에 신청 순서와 게만아의 상세 포스팅 링크가 있습니다. DB증권은 슈퍼 이동평균, 나머지 증권사는 패키지 안의 가이드 글이지만 세팅 방법은 같습니다.

    • 발급받은 키는 비밀번호와 같습니다. 따로 안전하게 보관하고 남에게 보여주지 마세요.
    • Starter 테스트 코드는 실전 계좌(REAL) 기준입니다. 실전 계좌용 키를 받으세요.

    됐는지 확인 · 앱 키와 앱 시크릿을 받았고, 증권사에 따라 필요한 계좌 정보(계좌번호 등)를 확인했으면 다음으로 갑니다.

  6. 키 넣고 첫 조회 실행

    1. Starter 폴더의 my증권사_StockInfo.yaml(예: myDBI_StockInfo.yaml)을 엽니다.
    2. REAL_APP_KEY, REAL_APP_SECRET 칸의 작은따옴표 '' 사이에 받은 값을 붙여 넣고 저장합니다. 한국투자·NH·토스처럼 계좌 정보 칸이 더 있는 증권사는 파일 안 주석과 증권사 안내를 따르세요.
    3. 증권사_KR_Test.py(예: DBI_KR_Test.py)를 열고 실행 → 디버깅 없이 실행 또는 오른쪽 위 ▶ 버튼으로 실행합니다.
    # myDBI_StockInfo.yaml 예시 (값은 예시 문구 대신 내 키로)
REAL_APP_KEY: '여기에 앱 키'
REAL_APP_SECRET: '여기에 앱 시크릿'

    됐는지 확인 · 터미널에 내 잔고, 보유 종목, 테스트 종목의 현재가, 일봉 데이터가 차례로 나오면 성공입니다. 내 실제 계좌가 코드와 연결된 것입니다. 토큰 관리 같은 복잡한 처리는 공통모듈이 알아서 합니다.

    테스트 코드 아래쪽의 매수·매도 주문 부분은 ''' 따옴표 세 개로 감싼 주석이라 실행되지 않습니다. 주문까지 확인하고 싶을 때만 Starter 글을 읽고 직접 주석을 풀어 보세요. 그때는 실제 주문이 나갑니다.

    막히면 · 토큰 발급 실패·검증 실패가 나면 키를 잘못 넣었거나 예시 문구가 남은 경우가 많습니다. → 오류 해결: 키 검증·토큰 발급 실패 · FileNotFoundError가 나면 → 파일을 찾지 못함

여기까지 됐다면

축하합니다. 내 PC에서 파이썬으로 내 계좌를 조회했습니다. 다음은 목적에 따라 고르세요.

  • Starter를 끝까지 체험 — 효율적 투자선으로 비중 계산 → 백테스트 → 리밸런싱 수량 계산 → 주문 구조 확인. Starter 글에서 이어집니다.
  • 유료 콘텐츠를 내 PC에서 자동 실행 — 2단계 · GMA Runner
  • 24시간 서버 운용 — 3단계 · AWS 서버

자주 묻는 질문

Starter에도 서버가 필요한가요?

아닙니다. Starter 예시는 1년에 한 번(또는 한 달에 한 번) 리밸런싱하는 정적 자산배분이라 내 PC에서 직접 실행하면 충분합니다.

이미 Python 3.15를 설치했어요.

3.14를 추가로 설치하세요. 여러 버전이 함께 있어도 됩니다. VS Code 오른쪽 아래 인터프리터에서 3.14를 고르면 됩니다. 3.15에서는 일부 모듈 설치가 실패할 수 있습니다.

설치 화면이 이 페이지와 달라요.

프로그램이 업데이트되면 화면이 바뀝니다. 같은 이름의 버튼을 찾거나, 화면을 캡처해 AI에게 '지금 Python을 설치하는 중인데 이 화면에서 무엇을 눌러야 해?'라고 물어보세요.

AI에게 설치를 물어봐도 되나요?

네, 게만아도 권장합니다. 예: '내 PC(Windows)에 Python 3.14와 VS Code를 설치하려고 해. 단계별로 알려줘.' 단, API 키나 계좌번호는 붙여 넣지 마세요.
