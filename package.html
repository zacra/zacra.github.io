게만아 파이썬 자동매매 패키지

하나의 전략이 아니라 주식·ETF·코인 자동매매 전략과 시스템 코드를 폭넓게 보유하고, 직접 선택·수정·확장하기 위한 코드 베이스입니다.

패키지의 핵심

AI가 코드를 만드는 시대에도 실제 계좌에서 계속 돌아가는 시스템에는 API 연동, 주문·체결, 데이터 오류, 서버 자동 실행, 백테스트, 예외처리 같은 많은 요소가 필요합니다. 패키지는 이 시행착오를 줄이기 위한 출발점입니다.

무엇이 들어 있나?

  • 90개 이상의 주식·코인 전략 및 시스템 코드
  • 주식·ETF 자산배분, 모멘텀, 분할매매, 리밸런싱 구조
  • 코인 현물·선물 자동매매 전략
  • 백테스트·데이터·자동화 시스템
  • 증권사·거래소 연동 모듈
  • AWS 서버 세팅 및 crontab 실행 가이드
  • 직접 소유한 코드를 AI와 함께 수정·확장할 수 있는 구조

주식 지원 범위

게만아 전체 자동매매 생태계는 한국투자증권, LS증권, DB증권, 키움증권, 토스증권, KB증권, NH투자증권까지 7개 증권사 환경을 다룹니다.

다만 일반 패키지의 증권사 공통모듈 목록과 슈퍼 이동평균 콘텐츠의 DB증권 기반 구현은 구분해야 합니다. 패키지에는 한국투자·LS·키움·토스·KB·NH 공통모듈이 포함되며, DB증권 기반은 슈퍼 이동평균 자산배분 쪽에서 제공됩니다.

코인 지원 범위

업비트, 빗썸, 코인원, 바이낸스를 지원합니다. 코인은 주식처럼 한 전략 파일에서 Broker만 바꾸는 방식이 아니라 거래소별로 따로 구현되어 있으며, myBithumb, myCoinone처럼 각 거래소용 공통모듈을 따로 사용합니다.

왜 ‘무기창고’라고 표현하나?

패키지는 모든 사람이 90개 전략을 동시에 쓰라는 의미가 아닙니다. 처음에는 안내 문서에 따라 필요한 전략 하나부터 시작하고, 이해와 경험이 쌓이면 투자 목적에 따라 전략과 시장을 넓혀가는 구조입니다.

AI와의 관계

AI는 새 코드를 빠르게 작성해주는 강력한 도구지만, 실제 운용 가능한 전략 구조와 API 연결, 오류처리, 백테스트까지 매번 처음부터 만들면 시행착오가 큽니다.

패키지는 이미 존재하는 코드를 출발점으로 삼아 “매매 조건을 바꿔줘”, “이 기능을 추가해줘”처럼 AI와 함께 수정하고 발전시키기 위한 코드 자산으로도 사용할 수 있습니다.

공통모듈에 없는 기능도 AI와 함께 확장할 수 있습니다

패키지의 증권사 공통모듈은 Starter보다 구현 범위가 넓지만, 증권사 공식 API의 모든 기능을 전부 함수로 만들어놓은 범용 SDK는 아닙니다. 게만아 전략과 실제 자동매매에서 필요한 기능을 중심으로 구현되어 있습니다.

그래서 자신에게만 필요한 API 기능이 있다면 기존 패키지 공통모듈을 AI에게 함께 보여주고, 해당 증권사의 공식 API 명세 링크를 제공한 뒤 기존 구조와 스타일을 유지하도록 요청하는 방식이 효율적입니다.

개인적으로는 코드베이스 전체를 보면서 수정하기 편한 Cursor를 주로 활용합니다. AI가 만든 코드는 항상 검토·테스트해야 하며, API 명세의 정본은 반드시 증권사 공식 문서입니다.

신규 콘텐츠 추가 방식

새 전략은 먼저 멤버십에서 연구·공개되고, 일정 기간 뒤 패키지로 편입되는 방식으로 운영됩니다. 멤버십은 패키지 이용에 필수라기보다 신규 연구 콘텐츠를 더 일찍 확인하는 선택지에 가깝습니다.

패키지 구매·다운로드

현재 제공 범위와 최신 코드 목록을 확인하고, 구매 후 코드를 다운로드하는 안내는 아래 패키지 페이지에서 진행합니다. GitHub 문서는 가격이나 한시적 이벤트보다 패키지의 구조와 역할을 설명하는 데 집중합니다.

패키지가 약속하지 않는 것

패키지는 특정 수익률을 약속하거나 종목을 추천하는 서비스가 아닙니다. 중요한 것은 수익률 하나가 아니라 MDD, 변동성, 장기 유지 가능성을 포함한 ‘안 깨지는 시스템’을 직접 구축하고 통제하는 것입니다.

패키지보다 하나의 장기 전략이 더 맞을 수도 있습니다

다양한 주식·코인 전략을 직접 선택하고 확장하고 싶다면 패키지가 맞고, 주식·ETF 장기 시스템 하나에 집중하고 싶다면 슈퍼 이동평균 자산배분이 더 단순한 선택입니다.
