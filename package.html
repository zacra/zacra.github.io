자주 묻는 질문

코딩 경험이 없어도 되나요?

처음에는 설정값과 실행 흐름만 익히면 됩니다. 단계별 가이드와 공식 카페가 있고, 필요할 때 AI와 함께 코드를 조금씩 수정·확장할 수 있습니다. 설치 따라하기도 참고하세요.

AWS 서버가 꼭 필요한가요?

아닙니다. 함께 제공되는 GMA Runner로 Windows·Mac PC에서 자동 실행할 수 있고, 24시간 운용이 필요할 때 AWS + crontab을 선택하면 됩니다.

클래스101 강의를 먼저 들어야 하나요?

아닙니다. 강의는 원리를 배우고 싶은 분을 위한 선택 사항이며, 패키지는 별도 가이드로 바로 시작할 수 있습니다.

단독 상품을 먼저 사도 되나요?

네. 슈퍼 이동평균 또는 코인 더블 이동평균 New를 단독(각 20만원)으로 먼저 구매한 뒤, 기존 구매금액을 인정받아 패키지로 차액 업그레이드할 수 있습니다. zacra007@gmail.com으로 문의해 주세요.

멤버십은 꼭 가입해야 하나요?

아닙니다. 월 15,000원 선택형 멤버십은 신규 콘텐츠를 먼저 보고 싶은 분을 위한 것이며, 일반 패키지에도 출시 120일 후 추가 결제 없이 편입됩니다.

완성된 수익 시스템인가요?

아닙니다. 여러 전략·백테스트 코드·공통모듈·실행 도구를 제공하는 교육·실습용 코드 콘텐츠이며, 특정 수익을 보장하지 않습니다. 포함된 전략이 모두 실전 검증됐다는 뜻도 아닙니다.
