패키지를 한 문장으로

현재 97개 콘텐츠의 전략·백테스트·공통모듈·자동화 코드를 필요한 것부터 골라 쓰고, 직접 보유한 소스 코드를 AI와 함께 수정·확장하는 시스템 투자 코드 베이스입니다.

이런 분에게 가장 잘 맞습니다

  • 국내주식뿐 아니라 미국주식·ETF·코인까지 여러 시장을 직접 시스템화하고 싶은 분
  • 추세추종·자산배분뿐 아니라 평균회귀·분할매매·돌파 등 여러 방법론을 코드로 비교하고 싶은 분
  • AI로 맨땅에서 다시 만들기보다 이미 사용해온 코드 구조를 출발점으로 빠르게 확장하고 싶은 분
  • 자동매매 서비스에 맡기기보다 매매 조건과 주문 로직을 직접 확인할 수 있는 소스 코드를 원하는 분

한국·미국주식, 자산배분, 모멘텀, 추세추종, 리밸런싱, 분할매매와 레버리지 ETF 아이디어를 다룹니다.

코인

업비트·빗썸·코인원·바이낸스의 현물·선물 전략과 거래소별 API 연결 구조를 다룹니다.

백테스트·자동화

과거 데이터 검증, 서버 실행, crontab, 메시지·운영 보조 시스템까지 실전 흐름으로 연결합니다.

떨사오팔(평균회귀), TQQQ·SOXL 분할매수처럼 널리 알려진 방식도 변형·연구할 수 있는 구현이 있습니다. 포함되어 있다는 것이 특정 전략을 추천한다는 뜻은 아니며, 자신의 위험 수준에 맞게 백테스트하고 수정하는 코드 자산으로 보는 것이 정확합니다.

게만아가 더 선호하는 방향은 분명합니다

다양한 전략을 구현하지만 핵심 운용 철학은 수익률 하나보다 MDD를 관리하고, 추세가 무너질 때 위험 노출을 줄이며, 자산배분과 현금을 활용해 오래 유지하는 구조에 더 가깝습니다.

평균회귀나 레버리지 ETF 분할매수는 강한 하락이 오래 이어지면 추가 매수와 변동성이 커질 수 있으므로, 패키지에서도 무조건적인 정답이 아니라 비교·검증·디벨롭의 대상으로 다룹니다. 게만아 투자 철학 보기 →

한국·미국주식과 멀티 증권사 구조

게만아 콘텐츠는 한국투자·LS·DB·키움·토스·KB·NH증권 환경을 다룹니다. 공통 인터페이스로 작성된 주식 전략은 전략 로직을 최대한 유지하면서 증권사·시장·계좌를 바꾸기 쉽게 구성합니다.

패키지에는 한국투자·LS·키움·토스·KB·NH 공통모듈이 포함되고, DB증권 지원 코드는 슈퍼 이동평균 전략에 포함됩니다. 증권사별 지원 시장과 세부 기능은 서로 다를 수 있습니다.

코인 자동매매와 멀티 거래소 구조

패키지는 주식만을 위한 코드가 아닙니다. 업비트·빗썸·코인원·바이낸스 환경의 코인 자동매매 전략과 봇, 거래소 API 연결 구조도 함께 다룹니다.

거래소마다 API 방식은 다르지만 전략·봇과 API 연결부를 분리해 두어, 기존 코드를 바탕으로 조건을 바꾸거나 새로운 전략·기능을 추가하기 쉽게 구성합니다. 현물은 물론 바이낸스 선물까지 다양한 시스템을 연구·확장할 수 있습니다.

AI 시대에 패키지의 가치는 ‘완제품’보다 좋은 출발 코드에 있습니다

AI는 코드를 빠르게 만들지만 실제 계좌에서는 인증·시세·주문·체결·예외처리·서버·백테스트가 함께 맞물려야 합니다. 빈 화면에서 시행착오를 반복하기보다 이미 사용해온 코드와 연결 구조를 AI에게 보여주고 필요한 조건과 기능만 수정하면 훨씬 빠르게 자신의 시스템으로 발전시킬 수 있습니다.

또한 소스 코드를 직접 받아 매매 조건과 주문 로직을 확인할 수 있으므로, 외부 서비스의 블랙박스에만 의존하지 않고 자신의 환경에서 이해·수정·운용할 수 있습니다. 이는 소스 코드의 열람·사용·수정을 뜻하며 저작권 자체의 양도를 의미하지 않습니다.

백테스트만이 아니라 실계좌에서도 계속 확인합니다

게만아 투자 실험실에서는 수익과 손실, 수익률과 MDD를 매월 결산합니다. 최근 공개된 주식·연금 메인 계좌는 연환산 수익률 약 20%대, MDD 약 -10% 수준을 기록하고 있지만 이 수치는 시장과 운용 기간에 따라 계속 달라집니다.

코인도 과거 특정 구간에서 비트코인이 전고점 대비 약 절반 수준까지 하락하는 동안 실계좌 낙폭을 -15% 미만 수준으로 방어한 사례를 공개했습니다. 모두 과거 기록이며 미래 성과를 보장하지 않습니다.
