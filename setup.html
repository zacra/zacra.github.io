시작 전 준비물

  • PC 한 대 — Windows 또는 Mac. 회사 PC는 프로그램 설치가 막혀 있을 수 있습니다.
  • 증권사 계좌 또는 코인 거래소 계정 — 주식은 한국투자·LS·키움·토스·KB·NH·DB·메리츠 중 한 곳, 코인은 업비트·빗썸·코인원(바이낸스는 패키지)
  • 구글 계정 — 무료 Starter 신청과 구글 드라이브 다운로드에 씁니다.
  • AWS를 쓸 경우 결제 카드 — AWS 가입 때 카드 등록이 필요합니다.
  • 나눠서 할 여유 — 한 번에 다 하지 않아도 됩니다. 단계 하나씩 끊어서 하세요.

세팅하면서 꼭 지킬 것

  • API 키·시크릿은 비밀번호입니다. 캡처해서 올리거나 카페·AI 질문에 붙여 넣지 마세요. 질문할 때는 키 부분을 지우고 올립니다.
  • 거래소 API에는 출금 권한을 주지 않습니다. 조회·주문에 필요한 권한만 켭니다.
  • 첫 실전은 작게 시작합니다. 투자 비중(InvestRate 등)을 낮게 두고, 주문 실행 여부 설정을 직접 확인합니다.
  • 설치 화면은 업데이트로 바뀔 수 있습니다. 화면이 조금 다르면 같은 이름의 버튼을 찾거나, 화면을 캡처해 AI에게 물어보세요.

그래도 안 되면 게만아 카페에 같은 내용(오류 출력과 일반 출력 모두)을 올려 주세요. 카페에 자주 올라온 설치·실행 오류는 오류 해결 페이지에 모아 두었습니다.

자주 묻는 질문

코딩을 몰라도 세팅할 수 있나요?

네. 각 단계에 따라 하는 순서와 됐는지 확인하는 방법을 적었습니다. 처음부터 코드 전체를 이해할 필요는 없고, 설정값과 실행 흐름부터 익힌 뒤 필요할 때 조금씩 넓혀 가면 됩니다.

AWS 서버가 꼭 필요한가요?

아닙니다. 전략이 도는 시간에 PC를 켜둘 수 있다면 GMA Runner로 충분합니다. 24시간 완전 자동화가 중요하거나 API에 고정 IP를 등록해야 할 때 AWS 같은 서버가 더 편합니다.

GMA Runner는 어디서 받나요?

별도로 판매하지 않고 게만아 패키지, 슈퍼 이동평균 자산배분, 코인 더블 이동평균 New 구매자의 구글 드라이브에 GMA_RUNNER.zip으로 함께 들어 있습니다. 무료 Starter에는 들어 있지 않습니다.

Python은 몇 버전을 설치하나요?

3.14를 권장합니다. 3.11~3.14를 쓸 수 있고, 2026년 10월에 나온 3.15는 일부 모듈(ccxt 등)이 아직 지원하지 않아 권장하지 않습니다. 이미 3.15가 있다면 3.14를 추가로 설치하세요.

세팅하다 막히면 어디에 물어보나요?

먼저 오류 해결 페이지에서 오류 문구로 찾아보세요. 없으면 이 페이지의 질문 틀로 AI에게 묻거나, 게만아 카페에 오류 출력과 일반 출력을 함께 올려 주세요.
