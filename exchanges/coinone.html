코인원 API 파이썬 자동매매 가이드

코인원 파이썬 자동매매는 ① 코인원 계정(KYC 인증) → ② Open API 메뉴에서 키 발급 → ③ Access Key·Secret Key를 공통모듈에 입력 → ④ 테스트 파일로 조회 확인 순서입니다. 코인원은 파이썬에서 쉽게 쓸 수 있는 공개 래퍼 라이브러리가 없어서 게만아가 공통모듈을 직접 구현했고, 한 계정 안에서 포트폴리오별로 API 키를 발급해 자산을 분리할 수도 있습니다.

게만아 코인원 공통모듈 대표 포스팅

코인원 API 연동과 공통모듈(패키지 54번)의 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 코인원 계정을 준비하고 KYC 인증을 마칩니다(가입 조건은 코인원 공지 확인).
  2. 코인원 페이지 맨 아래의 Open API 메뉴로 들어가 [통합 API 관리]를 누르고, 개인용 API에서 [새로운 키 발급]을 누릅니다.
  3. 키 이름을 정하고 잔고조회·주문조회·주문관리 권한을 선택한 뒤 약관에 동의하고 [API 생성]을 누릅니다.
  4. Access Key와 Secret Key를 복사해 안전하게 보관합니다(확인 후에는 다시 볼 수 없습니다).
  5. myCoinone.py 상단의 액세스 토큰·시크릿 키 변수에 입력하고 저장합니다. 필요한 라이브러리(httplib2)가 없다면 pip3 install httplib2로 설치합니다.
  6. Coinone_Test.py로 티커·잔고·현재가·캔들을 조회부터 확인합니다. 주문 예시는 주석을 풀어 가장 작은 금액으로 확인하세요.

게만아 공통모듈로 쓰면

코인원 공통모듈 myCoinone.py는 게만아 업비트 공통모듈(myUpbit.py)과 같은 구조로 만들어, 잔고·보유 코인 조회, 현재가, 캔들 조회, 시장가·지정가 주문, 미체결 주문 조회·취소를 같은 방식으로 호출합니다. 그래서 업비트용 전략을 코인원으로 옮겨 쓰기 쉽고, 같은 전략을 업비트와 코인원에서 나란히 운용하는 세컨 계좌도 만들 수 있습니다.

업비트와 가장 크게 다른 점은 종목 표기(KRW-BTC ↔ BTC)와 API 키를 넣는 위치입니다.

실전에서 주의할 점

  • Secret Key는 확인 버튼을 누르기 전에 복사하세요. 이후에는 다시 확인할 수 없습니다.
  • 종목 표기가 거래소마다 다릅니다. 코인원은 BTC, 업비트·빗썸은 KRW-BTC입니다. 다른 거래소 전략을 옮길 때는 표기를 확인하세요.
  • 필요한 권한만 선택하세요. 자동매매에는 잔고조회·주문조회·주문관리면 충분하며, 출금 권한은 주지 않는 것이 안전합니다.
  • 모듈 설치 오류에 대비하세요. 공통모듈이 쓰는 라이브러리(httplib2 등)가 서버에 설치돼 있지 않으면 봇이 오류로 멈춥니다. 서버에도 같은 라이브러리를 설치하세요.
  • 게시 시점(2024년 7월)과 현재의 가입 조건·수수료 정책은 다를 수 있습니다. 코인원 공지를 확인하세요.
  • 응답이 불안정할 때의 처리는 API 불안정 대응 가이드를 참고하세요.

자주 묻는 질문

코인원 API 키는 어디에서 발급받나요?

코인원 페이지 맨 아래의 Open API 메뉴에서 [통합 API 관리]를 누르고, 개인용 API의 [새로운 키 발급]을 눌러 이름과 권한(잔고조회·주문조회·주문관리)을 선택한 뒤 [API 생성]을 누르면 Access Key와 Secret Key가 나옵니다. Secret Key는 확인 후 다시 알 수 없으니 먼저 복사해 두세요.

코인원 API는 IP를 등록해야 하나요?

게만아 구현 기준으로 별도 IP 입력 없이 키를 발급합니다. IP 등록이 필요한 거래소는 업비트와 빗썸입니다.

코인원 API 권한은 무엇을 선택해야 하나요?

게만아는 잔고조회, 주문조회, 주문관리 정도를 선택합니다. 출금 같은 불필요한 권한은 주지 않는 것이 안전합니다.

코인원에도 포트폴리오별 API 키가 있나요?

네. 코인원은 포트폴리오 기능으로 한 계정 안에서 자산을 나누고 포트폴리오별로 API 키를 발급받아 서로 다른 전략을 분리해 운용할 수 있습니다. 이 포트폴리오는 Open API로만 매매할 수 있습니다.

코인원에는 pyupbit 같은 파이썬 모듈이 없나요?

업비트의 pyupbit나 빗썸의 pybithumb처럼 편하게 쓸 수 있는 래퍼가 코인원에는 마땅치 않아, 게만아는 코인원 공통모듈(myCoinone.py)을 직접 만들었습니다.

업비트 전략을 코인원에서 돌릴 수 있나요?

가능합니다. 코인원 공통모듈이 업비트 공통모듈과 같은 구조라서 옮기기 쉽습니다. 다만 종목 표기(KRW-BTC ↔ BTC)를 맞춰야 하고, 거래소마다 거래 환경이 달라 옮긴 뒤 백테스트와 소액 검증이 필요합니다.

근거와 확인 시점

이 페이지는 게만아의 코인원 파이썬 자동매매 시작 포스팅(패키지 54번, 2024-07-10 게시)과 업비트 포켓 포스팅(2026-09-01)의 코인원 포트폴리오 설명, 코인원 공식 API 문서를 정리한 것입니다. 이후 바뀐 발급 화면·권한·가입 조건은 반영되지 않았을 수 있습니다. 거래소의 API 사양과 정책, 가입·발급 조건은 바뀔 수 있으므로 키 발급과 실제 주문 전에 공식 문서의 최신 내용을 확인하세요.
