빗썸 API 파이썬 자동매매 가이드

빗썸 파이썬 자동매매는 ① 빗썸 계정 → ② Open API 메뉴에서 키 발급(허용 IP 필수) → ③ API Key·Secret Key를 공통모듈에 입력 → ④ 테스트 파일로 조회 확인 순서입니다. 특히 사용하는 환경의 IP를 입력해야 키 생성 버튼이 활성화되고, 자동매매에 쓰지 않는 입출금 권한은 체크하지 않는 것이 안전합니다.

게만아 빗썸 공통모듈 대표 포스팅

빗썸 API 연동과 공통모듈(패키지 60번)의 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 빗썸 계정을 준비합니다(가입 조건은 빗썸 공지 확인).
  2. 빗썸 사이트의 OpenAPI 메뉴에서 약관에 동의하고 필요한 권한만 체크합니다. 입출금 권한은 체크하지 않습니다.
  3. 허용 IP에 내 PC의 IP와 자동매매 서버의 IP를 입력하면 API Key 생성 버튼이 활성화됩니다.
  4. [API Key 생성] → 인증요청(휴대폰 인증)을 거쳐 API Key와 Secret Key를 복사해 안전하게 보관합니다.
  5. myBithumb.py에 키를 입력하고 저장합니다.
  6. Bithumb_Test.py로 티커·잔고·현재가·캔들을 조회부터 확인합니다. 주문 예시는 주석을 풀어 가장 작은 금액으로 확인하세요.

게만아 공통모듈로 쓰면

빗썸 공통모듈 myBithumb.py는 업비트 공통모듈·코인원 공통모듈과 같은 구조로 만들어, 잔고·보유 코인 조회, 현재가, 캔들 조회, 시장가·지정가 주문, 미체결 주문 조회·취소 같은 기능을 같은 방식으로 호출합니다. 업비트용으로 만든 전략을 빗썸으로 옮길 때는 종목 표기가 같아(KRW-BTC) 수정할 부분이 적습니다.

돌파 매매가 포함된 봇은 짧은 주기(예: 2분)로 실행하도록 crontab에 등록합니다. 패키지에서 _Test는 백테스트, _Bot은 실제 자동매매 봇, FixV는 고정 비중 버전입니다.

실전에서 주의할 점

  • 허용 IP는 필수입니다. 서버를 옮기거나 공인 IP가 바뀌면 허용 IP를 다시 확인하세요.
  • 입출금 권한은 체크하지 마세요. 자동매매에 필요하지 않은 권한은 주지 않는 것이 안전합니다.
  • Secret Key는 확인 버튼을 누르기 전에 복사하세요. 이후에는 다시 확인할 수 없습니다.
  • API 2.0 기준으로 확인하세요. 예전 1.0 기반 코드나 외부 라이브러리는 앞으로 사용이 막힐 수 있습니다.
  • 종목 표기가 거래소마다 다릅니다. 빗썸은 KRW-BTC, 코인원은 BTC입니다. 다른 거래소 전략을 옮길 때는 표기를 확인하세요.
  • 계정 가입 조건은 시점에 따라 바뀔 수 있습니다. 게시 시점(2024년 9월)에는 NH농협 계좌가 필요했습니다.
  • 응답이 불안정할 때의 처리는 API 불안정 대응 가이드를 참고하세요.

자주 묻는 질문

빗썸 API 키는 어떻게 발급받나요?

빗썸 사이트의 OpenAPI 메뉴에서 약관에 동의하고 권한을 체크한 뒤, 사용하는 환경의 IP를 입력해 [API Key 생성]을 누릅니다. 인증요청 버튼으로 휴대폰 인증을 하면 API Key와 Secret Key가 나옵니다. Secret Key는 확인 버튼을 누른 뒤 다시 알 수 없으니 먼저 복사해 두세요.

빗썸 API는 IP를 등록해야 하나요?

네, 필수입니다. IP를 입력해야 API Key 생성 버튼이 활성화됩니다. 게만아는 내 PC의 IP와 자동매매 서버의 IP를 함께 입력합니다.

빗썸 API 권한은 무엇을 체크해야 하나요?

자동매매에 필요한 조회·주문 관련 권한만 체크하고, 사용하지 않는 입출금 권한은 체크하지 않는 것을 권장합니다. 권한 이름과 화면은 바뀔 수 있으니 발급 화면의 안내를 확인하세요.

빗썸 API 1.0과 2.0 중 무엇을 써야 하나요?

빗썸이 최신 버전인 API 2.0을 권장하고 있고, 언젠가 1.0은 사용이 막힐 여지가 있어 게만아 공통모듈은 2.0 기준으로 직접 구현했습니다.

빗썸에서 쓸 수 있는 캔들(타임프레임)은 무엇인가요?

게만아 공통모듈의 캔들 조회는 1일, 4시간, 1시간, 30분, 15분, 10분, 5분, 3분, 1분봉을 지원합니다.

업비트 전략을 빗썸으로 옮길 수 있나요?

가능합니다. 빗썸 공통모듈은 업비트·코인원 공통모듈과 같은 구조이고 종목 표기도 업비트와 같은 KRW-BTC라서 옮기기 쉽습니다. 다만 거래소마다 가격 흐름과 거래 조건이 다르므로 같은 전략도 결과가 달라질 수 있어, 옮긴 뒤 백테스트와 소액 검증이 필요합니다.
