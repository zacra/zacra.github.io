LS증권 Open API 파이썬 자동매매 가이드

LS증권 Open API는 REST 방식이며 국내주식과 미국주식을 모두 다룹니다. 게만아 구현 기준 연동 순서는 ① LS증권 계좌 → ② (미국주식을 쓴다면) 해외주식 거래신청·실시간 시세신청 → ③ API 신청 → ④ 앱키·시크릿을 설정 파일(yaml)에 입력 → ⑤ 테스트 파일로 조회 확인입니다. 특히 미국주식은 API 발급 전에 신청을 먼저 해두는 것이 시행착오를 줄입니다.

게만아 LS증권 공통모듈 대표 포스팅

게만아 LS증권 공통모듈(패키지 76번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

방식REST API · OAuth 접근토큰. 국내주식 시세·계좌·현물주문·정정취소 기능이 TR 단위로 구분되며, TR별 호출 제한은 공식 문서에서 확인해야 합니다.
신청공식 이용안내를 따라 신청합니다. 게만아 포스팅에서는 웹의 [API 신청하기]가 웹앱 URL로 이동하는 문제가 있어(Mac 환경), LS증권 투혼 앱에서 “API”를 검색해 신청했습니다.
신청 항목xingAPI 신청을 먼저 하고, 이어서 OPEN API와 해외주식 API 신청까지 진행합니다. 신청 후 앱키와 시크릿키를 복사해 둡니다.
미국주식 사전 신청미국주식 자동매매를 할 거라면 API 발급 전에 앱의 [해외주식 거래신청]과 [해외주식 실시간 시세신청]을 먼저 완료하길 권장합니다(무료, 자동연장 선택). 게만아는 이를 미루고 API를 발급받았다가 미국 관련 API가 동작하지 않아, API를 다시 발급받고서야 해결했습니다.
허용 IP별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.
지원 시장국내주식(KR)과 미국주식(US)을 지원합니다. 게만아 공통모듈도 국내·미국 Helper를 제공하며, 미국주식 주문·정정·취소가 API로 동작하는 것을 확인했습니다(2025년 11월 포스팅 기준).
모의투자설정 파일에 VIRTUAL 항목은 있지만, 게만아 포스팅에서는 앱에서 모의계좌를 만드는 방법을 찾지 못해 모의계좌 없이 실계좌로 검증했습니다.
다계좌설정 파일에 REAL, REAL2, REAL3… 형식으로 계좌를 추가합니다. 토큰 파일 경로는 계좌마다 달라야 합니다.
수수료 혜택LS증권 API 활용 매매 수수료 혜택은 별도 안내 포스팅에 정리돼 있습니다. 혜택 조건은 바뀔 수 있으니 해당 안내와 LS증권 공지를 확인하세요.
게만아 연결Broker="LS" · 패키지 76번 · 파일 LS_Common.py, LS_API_Helper_KR.py, LS_API_Helper_US.py, 설정 파일 myLS_StockInfo.yaml, 테스트 LS_KR_Test.py
서버 배치AWS 서버라면 공통모듈 3개 파일과 봇은 /var/autobot에, 설정 파일 myLS_StockInfo.yaml은 /home/ec2-user에 둡니다. 토큰 파일 경로를 ./…json으로 통일했기 때문에, 내 PC에서는 현재 폴더에, 서버에서는 /home/ec2-user에 생성됩니다.

파이썬 자동매매 연동 순서

  1. LS증권 계좌를 준비합니다.
  2. 미국주식도 쓸 거라면 LS증권 앱에서 해외주식 거래신청과 해외주식 실시간 시세신청을 먼저 합니다.
  3. 앱(투혼)에서 “API”를 검색해 xingAPI → OPEN API → 해외주식 API 순서로 신청합니다.
  4. 앱키와 시크릿키를 복사해 myLS_StockInfo.yaml의 REAL_APP_KEY, REAL_APP_SECRET에 넣습니다.
  5. LS_KR_Test.py로 조회부터 확인합니다. 이 파일에는 매수·매도 테스트 함수도 있으니 매매를 원치 않으면 주석 처리하고 확인하세요.
  6. 봇의 증권사를 LS로 바꾸고(Broker="LS", accountMode="REAL"), 주문은 가장 작은 수량으로 먼저 확인합니다.

설정 파일(myLS_StockInfo.yaml)은 이렇게 채웁니다

발급받은 앱키와 시크릿을 REAL 항목에 넣으면 됩니다. 실계좌가 2개라면 REAL_URL만 빼고 REAL2로 복사해 만들면 되고, 3개라면 REAL3까지 같은 규칙으로 늘립니다.

# 실계좌 정보
REAL_APP_KEY: "여러분의 앱키"
REAL_APP_SECRET: "여러분의 앱시크릿"
REAL_TOKEN_PATH: './ls_real_token.json'
REAL_URL: 'https://openapi.ls-sec.co.kr:8080'

# 실계좌 2 (계좌가 2개일 때)
REAL2_APP_KEY: "여러분의 앱키"
REAL2_APP_SECRET: "여러분의 앱시크릿"
REAL2_TOKEN_PATH: './ls_real2_token.json'

# 모의계좌 정보
VIRTUAL_APP_KEY: ''
VIRTUAL_APP_SECRET: ''
VIRTUAL_TOKEN_PATH: './ls_virtual_token.json'
VIRTUAL_URL: 'https://openapi.ls-sec.co.kr:8080'

REAL_TOKEN_PATH와 REAL2_TOKEN_PATH의 값은 꼭 달라야 합니다.

게만아 공통모듈로 쓰면

LS증권 공통모듈은 한국투자증권·DB증권과 같은 함수를 제공해서 서로 호환됩니다(DBI_Common ↔ KIS_Common ↔ LS_Common, 국내·미국 Helper도 같은 방식). 최신 봇은 상단의 Broker·accountMode 값만 바꾸면 되고, 예전 방식의 봇은 import KIS_Common as Common을 import LS_Common as Common으로, KIS_API_Helper_KR을 LS_API_Helper_KR로 바꾸면 됩니다.

Broker = "LS"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2·VIRTUAL 등)

한국투자·DB증권과 같은 함수 규격이라 같은 봇을 증권사만 바꿔 쓸 수 있습니다. 계좌를 바꿀 때는 Common.SetChangeMode("REAL2")처럼 계좌명을 바꿉니다.

실전에서 주의할 점

  • 미국주식을 쓸 거라면 API 발급 전에 해외주식 거래신청·실시간 시세신청부터 하세요. 나중에 신청하면 미국 관련 API가 동작하지 않을 수 있습니다(게만아는 API를 재발급해 해결했습니다).
  • 테스트 파일에는 매수·매도 함수도 들어 있습니다. 매매를 원치 않으면 해당 부분을 주석 처리한 뒤 실행하세요.
  • 계좌를 여러 개 쓸 때 토큰 파일 경로가 겹치면 안 됩니다. REAL_TOKEN_PATH와 REAL2_TOKEN_PATH의 값은 서로 달라야 합니다.
  • 앱키·시크릿·토큰 파일은 비밀번호와 같습니다. 노출됐다면 폐기 후 재발급하세요.
  • 잘 안 되는 부분은 게만아 지원 카페에서 문의할 수 있습니다.

자주 묻는 질문

LS증권 API로 미국주식도 자동매매할 수 있나요?

가능합니다. LS증권 REST API가 미국주식을 지원하고, 게만아 공통모듈도 국내(KR)와 미국(US) Helper를 제공합니다. 게만아 포스팅(2025년 11월)에서 미국주식 주문·정정·취소가 API로 동작하는 것을 확인했습니다.

LS증권 API 신청은 어디에서 하나요?

공식 이용안내(openapi.ls-sec.co.kr/howto-use)를 따르면 됩니다. 웹의 [API 신청하기]가 웹앱 URL로 이동하는 경우가 있어, 게만아는 LS증권 투혼 앱에서 “API”를 검색해 신청했습니다. xingAPI 신청 후 OPEN API와 해외주식 API 신청까지 하면 앱키와 시크릿키를 복사할 수 있습니다.

LS증권 미국주식 API가 동작하지 않으면 어떻게 하나요?

미국주식을 쓸 거라면 API 발급 전에 [해외주식 거래신청]과 [해외주식 실시간 시세신청]을 먼저 해야 합니다. 이를 나중에 하면 미국 관련 API가 동작하지 않는 경우가 있었고, 게만아는 API를 다시 발급받아 해결했습니다.

LS증권 API는 IP를 등록해야 하나요?

게만아 구현 기준으로 별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.

LS증권 모의투자로 먼저 테스트할 수 있나요?

설정 파일에 VIRTUAL 항목은 있습니다. 다만 게만아 포스팅에서는 앱에서 모의계좌를 만드는 방법을 찾지 못해 모의계좌를 만들지 않고 실계좌로 검증했습니다. 실계좌로 테스트할 때는 조회부터 하고 주문은 가장 작은 수량으로 하세요.

한국투자증권용 봇을 LS증권으로 바꾸려면 어떻게 하나요?

최신 봇은 상단의 Broker를 "LS"로 바꾸면 됩니다. 예전 방식의 봇은 KIS_Common·KIS_API_Helper_KR import를 LS_Common·LS_API_Helper_KR로 바꾸면 됩니다. 공통모듈이 같은 함수 규격이라 전략 코드는 그대로 씁니다.

근거와 확인 시점

이 페이지는 게만아의 LS증권 공통모듈 구현 포스팅(2025-11-09 게시)에서 직접 구현·운용하며 확인한 내용과 LS증권 공식 개발 문서를 정리한 것입니다. 이후 바뀐 사양은 반영되지 않았을 수 있습니다. API 사양과 정책은 바뀔 수 있으므로 키 발급과 실제 주문 전에 공식 문서의 최신 내용을 확인하세요.
