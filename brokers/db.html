DB증권 Open API 파이썬 자동매매 가이드

DB증권 Open API는 OAuth 인증을 기반으로 국내·해외주식, 파생, 장내채권과 실시간 API를 제공하며 공식 Python 샘플·SDK·MCP 개발지원도 운영합니다.

공식 문서에서 확인할 핵심

  • Open API 신청 후 App Key/App Secret과 접근토큰을 이용해 인증합니다.
  • 국내주식 주문·시세뿐 아니라 해외주식, 파생, 장내채권 관련 API 카테고리가 공식 포털에 공개되어 있습니다.
  • 공식 Python 샘플과 SDK, MCP 기반 AI 코딩 지원 자료를 제공합니다.
  • 토큰 발급 빈도·유효기간과 상세 호출 제한은 공식 이용안내의 최신 내용을 확인해야 합니다.

게만아 Starter에서의 위치

무료 Starter에서 DB증권 버전을 선택해 국내주식 Lite 기준의 자동매매 흐름을 체험할 수 있습니다.

Starter는 전략을 이해하고 실제 계좌 연결 흐름을 경험하기 위한 Lite 예제입니다. 세부 주문유형·호출 제한·거래시간·거래소 구분은 반드시 최신 공식 문서를 다시 확인하세요.
