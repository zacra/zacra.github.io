DB증권 Open API 파이썬 자동매매 가이드

DB증권 Open API는 OAuth 인증을 기반으로 국내·해외주식, 파생, 장내채권과 실시간 API를 제공합니다. 게만아의 DB증권 지원 코드는 슈퍼 이동평균 자산배분 전략 구성 안에 포함돼 있으며, 국내·미국주식 Helper를 모두 제공합니다. 한국투자증권 기반 코드를 옮길 때는 미국 종목코드 표기가 다르다는 점을 꼭 확인하세요.

게만아 DB증권 대표 포스팅

게만아의 DB증권 지원 코드는 슈퍼 이동평균 자산배분 전략 구성 안에 포함되어 있습니다. DB증권으로 구현한 전략과 연결 과정은 게만아 블로그의 대표 포스팅에서 설명합니다.

방식OAuth 인증 기반 REST Open API. App Key/App Secret과 접근토큰으로 인증합니다. 토큰 유효기간과 호출 제한은 공식 이용안내의 최신 내용을 확인해야 합니다.
공식 지원 범위국내주식 주문·시세뿐 아니라 해외주식, 파생, 장내채권 API 카테고리와 실시간 API가 공개돼 있고, 공식 Python 샘플·SDK·MCP 기반 AI 코딩 지원 자료도 제공합니다.
허용 IP별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.
지원 시장(공통모듈)국내주식(KR)과 미국주식(US) Helper를 제공합니다(DBI_API_Helper_KR, DBI_API_Helper_US).
게만아 연결Broker="DBI" · 슈퍼 이동평균 자산배분 V2 구성에 포함. 다른 증권사처럼 별도 범용 공통모듈 묶음으로 제공되는 것은 아닙니다. 현재 신규 통합 패키지에는 슈퍼 이동평균 V2가 함께 포함됩니다.
토큰공통모듈이 내부적으로 토큰을 자동 발행합니다. 따로 발행하지 않아도 됩니다.
다계좌다계좌 운용은 설정 파일(yaml)만 바꾸면 됩니다.
미국 종목코드 표기증권사마다 미국 종목코드 인식이 다릅니다. 버크셔 해서웨이 B주는 한국투자증권에서 BRK/B, DB증권에서 BRK.B로 바꿔야 정상 인식됩니다(2025년 7월 포스팅에서 확인). 그래서 같은 기능이라도 증권사별 종목 목록 파일을 따로 둡니다(예: MakeGetTopStockForKIS.py와 MakeGetTopStockForDBI.py).
파일 경로DB증권 구현은 내 PC와 서버 모두 ./ 경로로 파일을 관리합니다. 한국투자증권 기반의 예전 패키지 콘텐츠는 서버에서 /var/autobot 경로를 쓰던 부분이 달랐습니다(2025년 7월 포스팅 기준).

파이썬 자동매매 연동 순서

  1. DB증권 계좌를 준비합니다.
  2. 공식 이용절차에 따라 Open API를 신청하고 App Key·App Secret을 발급받습니다.
  3. 발급받은 키를 DB증권용 설정 파일(yaml)에 넣습니다. 세팅 과정은 위 대표 포스팅에 설명돼 있습니다.
  4. 조회부터 테스트(잔고 → 보유종목 → 현재가)한 뒤, 주문은 가장 작은 수량으로 확인합니다.
  5. 미국주식 종목코드는 DB증권 표기(예: BRK.B)에 맞는지 확인합니다.

게만아 공통모듈로 쓰면

DB증권 공통모듈은 한국투자증권·LS증권과 같은 함수를 제공합니다(DBI_Common ↔ KIS_Common ↔ LS_Common, 국내·미국 Helper도 같은 방식). 그래서 한국투자증권용 봇을 DB증권용으로 바꾸거나 반대로 바꾸는 일이 간단합니다. DB증권 지원 코드는 슈퍼 이동평균 자산배분 구성에 들어 있습니다.

Broker = "DBI"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2 등)

한국투자·LS증권과 같은 함수 규격이라 같은 봇을 증권사만 바꿔 쓸 수 있습니다. 다만 DB증권 코드는 슈퍼 이동평균 자산배분 전략 구성 안에 있고, 다른 증권사 공통모듈처럼 별도 묶음으로 제공되지는 않습니다.

실전에서 주의할 점

  • 미국 종목코드 표기를 증권사별로 확인하세요. 같은 종목이 한국투자증권과 DB증권에서 다르게 표기될 수 있습니다(예: BRK/B ↔ BRK.B).
  • DB증권 지원 코드는 슈퍼 이동평균 자산배분 V2 구성에 포함됩니다. 다른 7개 증권사처럼 별도 범용 공통모듈 묶음이라는 뜻은 아닙니다.
  • 파일 경로 기준을 확인하세요. DB증권 구현은 PC와 서버 모두 ./ 경로 기준이라, 한국투자증권 기반 예전 콘텐츠의 서버 경로와 다를 수 있습니다.
  • 앱키·시크릿·토큰은 비밀번호와 같습니다. 노출됐다면 폐기 후 재발급하세요.

자주 묻는 질문

DB증권 API로 미국주식도 자동매매할 수 있나요?

가능합니다. 게만아 DB증권 지원 코드는 국내(KR)와 미국(US) Helper를 제공하며, 슈퍼 이동평균 자산배분 전략으로 미국주식 포트폴리오를 운용하도록 구성돼 있습니다.

DB증권 지원 코드는 어디에 들어 있나요?

슈퍼 이동평균 자산배분 V2 구성 안에 포함돼 있습니다. 현재 신규 통합 패키지에는 슈퍼 이동평균 V2가 함께 포함되므로 신규 구매자는 DB증권 코드도 함께 이용할 수 있습니다. 다만 다른 증권사처럼 별도 범용 공통모듈 묶음은 아닙니다.

한국투자증권과 DB증권은 미국 종목코드가 같은가요?

항상 같지는 않습니다. 버크셔 해서웨이 B주는 한국투자증권에서 BRK/B, DB증권에서 BRK.B로 바꿔야 정상 인식됩니다. 그래서 종목 목록을 만드는 파일도 증권사별로 따로 둡니다.

DB증권은 토큰을 직접 발급해야 하나요?

아니요. 게만아 공통모듈이 내부적으로 토큰을 자동으로 발행합니다.

DB증권 API는 IP를 등록해야 하나요?

게만아 구현 기준으로 별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.

DB증권 계좌를 여러 개 운용하려면?

설정 파일(yaml)만 바꾸면 됩니다. 계좌명은 accountMode 값으로 고릅니다.
