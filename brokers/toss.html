토스증권 Open API 파이썬 자동매매 가이드

토스증권 Open API로 파이썬 자동매매를 하려면 ① 토스증권 계좌 → ② PC에서 Open API Key 발급 → ③ 자동매매를 실행할 환경의 IP 등록 → ④ OAuth 토큰으로 조회·주문 순서로 진행합니다. 국내주식과 미국주식을 한 계좌에서 다루고, 게만아 공통모듈에서는 Broker 값을 "TOSS"로 바꿔 같은 전략을 실행합니다.

게만아 토스증권 공통모듈 대표 포스팅

게만아 토스증권 공통모듈(패키지 88번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 토스증권 계좌를 준비합니다.
  2. PC에서 토스증권 웹에 로그인해 Open API 메뉴 → “Open API Key 설정”에서 API Key와 Secret Key를 발급받습니다. 특히 Secret Key는 발급 직후 복사해 안전한 곳에 보관하세요.
  3. 허용 IP에 자동매매를 실행할 PC나 서버의 IP를 등록합니다. AWS 같은 서버를 쓴다면 그 서버의 고정 IP를 넣습니다.
  4. 설정 파일(yaml)에 키·시크릿, 토큰 저장 경로, API 주소를 넣습니다. 계좌 식별값을 비워 두면 계좌 목록 조회로 자동 설정됩니다.
  5. 조회부터 테스트합니다. 장 개장 여부 → 잔고 → 보유종목 → 현재가 순서로 확인하세요.
  6. 주문은 마지막에, 가장 작은 수량(1주)으로 확인합니다.

게만아 공통모듈로 쓰면

토스증권 공통모듈은 한국투자·LS·키움·DB증권과 같은 함수 규격으로 만들어져 있어서, 전략 코드의 증권사 설정만 바꾸면 같은 전략을 토스증권에서 실행할 수 있습니다.

Broker = "TOSS"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식
accountMode = "REAL"    # 토스증권은 REAL 고정

장 개장 여부 IsMarketOpen · 잔고 GetBalance · 보유종목 GetMyStockList · 현재가 GetCurrentPrice · 시장가·지정가 매수/매도 MakeBuyMarketOrder 등 · 주문 조회 GetOrderList

실전에서 주의할 점

  • 시장가 주문도 즉시 체결이 보장되지 않습니다. 주문 직후 몇 초 기다려도 체결 완료가 보장되지 않으므로, 체결 여부를 다시 조회해 확인해야 합니다.
  • 허용 IP와 실제 실행 환경의 IP가 다르면 호출이 거절될 수 있습니다. 서버를 옮기거나 공인 IP가 바뀌면 다시 등록하세요.
  • API Key·Secret·접근 토큰은 비밀번호와 같습니다. 화면 캡처나 공개 저장소에 노출되지 않게 하고, 노출됐다면 폐기 후 재발급하세요.
  • 계좌 구조, 호출 제한, 주문 유형은 바뀔 수 있으므로 실제 구현 전 공식 문서의 최신 내용을 확인하세요.

자주 묻는 질문

토스증권 API 키는 어디에서 발급하나요?

PC에서 토스증권 웹에 로그인한 뒤 Open API 메뉴의 “Open API Key 설정”에서 API Key와 Secret Key를 발급합니다. 이때 허용 IP도 함께 등록합니다.

토스증권 API로 미국주식도 자동매매할 수 있나요?

가능합니다. 토스증권 Open API는 국내주식과 미국주식을 함께 제공하며, 게만아 공통모듈도 국내(KR)와 미국(US) Helper를 따로 제공합니다. 설정 값 Market으로 선택합니다.

허용 IP는 왜 등록하고, 내 PC에서도 쓸 수 있나요?

IP 등록은 허용된 환경에서만 API를 호출하게 하는 보안 장치입니다. 내 PC에서도 쓸 수 있지만 공인 IP가 바뀌면 다시 등록해야 할 수 있습니다. 24시간 안정 운용이 목적이라면 고정 IP가 있는 서버가 편합니다. GMA Runner로 PC에서 시작하는 방법 →

토스증권 모의투자로 먼저 테스트할 수 있나요?

게만아 공통모듈은 실계좌(REAL) 기준으로 제공되므로 가장 작은 수량으로 조회부터 확인하는 방식을 권합니다. 모의 환경 제공 여부는 공식 문서에서 확인하세요.

다른 증권사로 만든 전략을 토스증권으로 옮기려면 코드를 다시 써야 하나요?

아니요. 공통 인터페이스로 작성된 주식 전략은 Broker 값을 "TOSS"로 바꾸는 것으로 전환합니다. 다만 증권사별 지원 시장과 주문 유형은 다를 수 있습니다. 멀티 증권사 구조 보기 →
