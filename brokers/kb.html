KB증권 Open API 파이썬 자동매매 가이드

KB증권도 REST 방식의 Open API를 제공합니다. 게만아 구현 기준 연동 순서는 ① KB증권 계좌 → ② Open API 신청(KB M-able 앱 또는 웹) → ③ App Key·App Secret 복사 → ④ 설정 파일(yaml)에 입력 → ⑤ 테스트 파일로 조회 확인입니다. 게시 시점에는 일반 계좌의 국내·미국주식을 지원했고, ISA·연금 계좌는 가능해질 예정이라고 안내돼 있었습니다.

게만아 KB증권 공통모듈 대표 포스팅

게만아 KB증권 공통모듈(패키지 95번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

방식REST API · 토큰 기반 인증. 공식 포털에서 시세·종목·계좌·잔고 조회와 주문·체결 API 문서, 개발가이드, GitHub·챗봇 같은 개발지원 진입점을 제공합니다.
서비스 상태KB증권은 개인 고객 대상 Open API를 2026년 7월 20일 오픈베타로 시작했고, 11월까지 후속 업그레이드로 제공 범위와 이용 대상을 단계적으로 확대한다고 밝혔습니다(언론 보도). 지원 계좌·상품 범위는 바뀔 수 있습니다.
신청KB증권 홈페이지 고객서비스 → Open API 메뉴에서 본인인증 후 신청하거나(언론 보도), KB증권 Open API 포털의 안내(웹)를 따르거나, 모바일 KB증권 앱(KB M-able)의 통합검색에서 “API”를 검색해 [Open API 신청하기]로 진행합니다. 끝까지 진행하면 App Key와 App Secret을 복사할 수 있습니다.

다계좌설정 파일에 REAL, REAL2처럼 숫자를 붙여 계좌를 추가합니다. 토큰 파일명도 계좌마다 달라야 합니다(예: kb_real2_token.json).
게만아 연결Broker="KB" · 패키지 95번 · 파일 KB_Common.py, KB_API_Helper_KR.py, KB_API_Helper_US.py, 설정 파일 myKB_StockInfo.yaml
연결 확인KB_KR_Test.py(국내), KB_US_Test.py(미국)로 확인합니다. 장 개장 여부 → 잔고 → 보유종목 → 현재가를 조회하고, 시장가·지정가 주문과 주문 목록 조회는 주석을 풀어서 확인하는 구성입니다.
서버 배치AWS 서버라면 공통모듈 3개 파일은 /var/autobot에, 설정 파일 myKB_StockInfo.yaml은 /home/ec2-user에 둡니다. 토큰 파일 경로를 ./…json으로 통일해 내 PC에서는 현재 폴더에, 서버에서는 /home/ec2-user에 생성됩니다.

파이썬 자동매매 연동 순서

  1. KB증권 계좌를 준비합니다.
  2. 웹 안내를 따르거나 KB M-able 앱 통합검색에서 “API”를 검색해 [Open API 신청하기]를 진행합니다.
  3. 발급 화면의 App Key와 App Secret을 각각 복사해 잘 저장해 둡니다.
  4. myKB_StockInfo.yaml의 REAL_APP_KEY, REAL_APP_SECRET에 입력합니다.
  5. KB_KR_Test.py, KB_US_Test.py로 조회부터 확인합니다.
  6. 봇의 Broker를 "KB"로, accountMode를 "REAL"로 바꾸고, 주문은 가장 작은 수량으로 먼저 확인합니다.

설정 파일(myKB_StockInfo.yaml)은 이렇게 채웁니다

복사해 둔 App Key와 App Secret을 REAL 항목에 넣으면 끝입니다. 계좌가 2개라면 REAL2를 같은 형식으로 추가하고, 토큰 파일명에도 2를 붙여 서로 다르게 합니다.

# 실계좌 정보
REAL_APP_KEY: '여러분의 APP KEY'
REAL_APP_SECRET: '여러분의 APP SECRET'
REAL_TOKEN_PATH: './kb_real_token.json'

# 실계좌2 정보 (계좌가 2개일 때)
REAL2_APP_KEY: '여러분의 APP KEY'
REAL2_APP_SECRET: '여러분의 APP SECRET'
REAL2_TOKEN_PATH: './kb_real2_token.json'

게만아 공통모듈로 쓰면

KB증권 공통모듈도 다른 증권사와 같은 함수 규격으로 맞춰져 있어(KB_Common, KB_API_Helper_KR, KB_API_Helper_US), 패키지의 주식 봇은 상단의 증권사 설정만 바꾸면 KB증권 계좌에서 운용할 수 있습니다. 계좌가 여러 개라면 accountMode를 "REAL" ↔ "REAL2" ↔ "REAL3"처럼 바꿉니다.

Broker = "KB"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식 (봇마다 지원 시장이 다르니 봇 주석을 따르세요)
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2·REAL3 등)

다른 증권사 공통모듈과 같은 함수 규격이라 같은 봇을 증권사만 바꿔 쓸 수 있습니다. 한국투자·LS·키움·토스증권에서 쓰던 봇도 Broker 값만 바꾸면 KB증권으로 옮길 수 있습니다.

실전에서 주의할 점

  • 게시 시점에는 일반 계좌만 지원했습니다. ISA·연금 계좌는 가능해질 예정이라는 안내였으니, 절세 계좌 자동매매를 계획한다면 현재 지원 여부를 공식 안내에서 먼저 확인하세요.
  • 테스트 파일의 주문 부분은 주석을 풀면 실제 주문이 나갑니다. 조회 부분을 먼저 확인하고, 주문은 가장 작은 수량으로 하세요.
  • 계좌를 여러 개 쓸 때 토큰 파일명이 겹치면 안 됩니다. REAL과 REAL2의 TOKEN_PATH는 서로 달라야 합니다.
  • 봇의 Market 설정을 함부로 바꾸지 마세요. 국내상장 전용으로 만든 봇은 시장을 바꾸면 봇 이름과 주문 시장이 어긋날 수 있습니다.
  • 앱키·시크릿·토큰 파일은 비밀번호와 같습니다. 노출됐다면 폐기 후 재발급하세요.

자주 묻는 질문

REST API는 무엇이고 왜 자동매매에 유리한가요?

Open API는 외부에 공개된 API 서비스이고, REST API는 HTTP 요청으로 쉽게 호출할 수 있는 API 구조입니다. 예전 증권사 API는 윈도우 프로그램·ActiveX·COM·HTS 연동처럼 특정 운영체제나 프로그램에 묶이는 경우가 많았지만, REST 방식은 파이썬 requests 같은 라이브러리로 호출할 수 있어 윈도우뿐 아니라 맥·리눅스·AWS 서버에서도 쓰기 쉽습니다.

KB증권 API 키는 어디에서 발급받나요?

KB증권 Open API 포털의 웹 안내를 따르거나, 모바일 KB증권 앱(KB M-able)의 통합검색에서 “API”를 검색해 [Open API 신청하기]를 진행하면 됩니다. 끝까지 진행하면 App Key와 App Secret을 복사할 수 있습니다.

KB증권 API로 ISA·연금 계좌도 자동매매할 수 있나요?

게만아 포스팅 게시 시점(2026년 8월)에는 일반 계좌의 국내·미국주식만 지원했고, ISA·연금 같은 절세 계좌는 가능해질 예정이라고 안내됐습니다. 현재 상태는 KB증권 공식 안내에서 확인하세요.

KB증권 API로 미국주식도 자동매매할 수 있나요?

일반 계좌 기준으로 가능합니다. 게만아 공통모듈도 국내(KR)와 미국(US) Helper를 제공하고, 테스트 파일도 KB_KR_Test.py와 KB_US_Test.py로 나뉘어 있습니다.

KB증권 API는 IP를 등록해야 하나요?

게만아 구현 기준으로 별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.

KB증권 계좌를 여러 개 자동매매하려면 어떻게 하나요?

설정 파일에 REAL2, REAL3처럼 숫자를 붙여 계좌를 추가하고 accountMode를 바꾸면 됩니다. 토큰 파일명도 계좌마다 달라야 합니다.

근거와 확인 시점

이 페이지는 게만아의 KB증권 공통모듈 구현 포스팅(2026-08-09 게시)에서 직접 구현·운용하며 확인한 내용을 KB증권 공식 포털 안내와 언론 보도로 대조해 정리한 것입니다. 지원 계좌·상품 범위는 바뀔 수 있어 이후 변경은 반영되지 않았을 수 있습니다. API 사양과 정책은 바뀔 수 있으므로 키 발급과 실제 주문 전에 공식 문서의 최신 내용을 확인하세요.
