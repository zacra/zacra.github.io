KB증권 Open API 파이썬 자동매매 가이드

KB증권 Open API 포털은 Token 기반 인증 환경에서 시세·종목·계좌·잔고 조회와 주문·체결 등 자동화 개발에 필요한 기능을 안내합니다.

공식 문서에서 확인할 핵심

  • KB증권 계좌 및 Open API 서비스 신청 후 앱키를 발급받아 인증 절차를 진행합니다.
  • 공식 포털에서 시세·종목·계좌·잔고·주문 관련 API 문서와 개발가이드를 확인할 수 있습니다.
  • 공식 포털에서 GitHub와 챗봇 같은 개발지원 진입점을 제공합니다.
  • 세부 지원 상품, 호출 제한, 주문 사양은 최신 API 문서에서 확인해야 합니다.

게만아 Starter에서의 위치

무료 Starter에서 해당 증권사 버전을 선택하면 국내주식 기준으로 계좌 조회·보유종목·리밸런싱·주문 흐름을 확인할 수 있습니다.

Starter는 전체 흐름을 이해하기 위한 Lite 예제입니다. 세부 주문유형·호출 제한·거래시간·지원 시장은 최신 공식 문서를 다시 확인하세요.
