키움증권 REST API 파이썬 자동매매 가이드

키움증권 REST API로 파이썬 자동매매를 하려면 ① 키움증권 계좌 → ② [API 사용신청] → ③ 앱키·시크릿 발급 → ④ 허용 IP 등록 → ⑤ OAuth 토큰으로 호출 순서로 진행합니다. 별도 OCX 설치 없이 Windows·macOS·Linux 서버에서 쓸 수 있고 국내주식과 미국주식을 모두 다룰 수 있으며, 게만아 구현 기준으로 한국투자·LS·DB증권과 달리 IP 등록이 필요하다는 점이 특징입니다.

게만아 키움증권 공통모듈 대표 포스팅

게만아 키움증권 공통모듈(패키지 77번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 키움증권 계좌를 준비합니다.
  2. 키움 REST API 사이트 우측 상단의 [API 사용신청]을 진행합니다.
  3. 앱키와 앱시크릿을 발급받습니다.
  4. 허용 IP에 내 PC의 IP와 자동매매할 서버의 IP를 등록합니다.
  5. 설정 파일(yaml)의 계좌 항목에 앱키·앱시크릿을 넣습니다. 모의투자는 VIRTUAL 항목에 모의 계좌용 키를 넣습니다.
  6. 조회부터 테스트한 뒤(잔고 → 보유종목 → 현재가), 주문은 마지막에 가장 작은 수량으로 확인합니다.

게만아 공통모듈로 쓰면

키움증권 공통모듈도 한국투자·LS·DB증권과 같은 함수 규격입니다. 한국투자증권용으로 작성된 주식 봇을 키움증권용으로 바꿀 때는 KIS_Common ↔ KIW_Common, KIS_API_Helper_KR ↔ KIW_API_Helper_KR로 바꿔 쓰거나, 증권사 설정 값을 바꾸는 방식을 씁니다.

Broker = "KIW"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2·VIRTUAL 등)

한국투자·LS·DB·토스와 같은 규격: 잔고 GetBalance · 보유종목 GetMyStockList · 현재가 GetCurrentPrice · 시장가·지정가 주문 등

실전에서 주의할 점

  • IP가 바뀌면 매매가 멈출 수 있습니다. 서버를 옮기거나 공인 IP가 바뀌면 허용 IP를 다시 등록하세요. 그래서 24시간 운용에는 고정 IP 서버가 권장됩니다.
  • 계좌를 여러 개 쓸 때 토큰 파일 경로가 겹치면 안 됩니다. REAL과 REAL2의 토큰 저장 경로는 서로 달라야 합니다.
  • 국내(KR)와 미국(US) Helper를 구분해 쓰세요. 봇의 Market 값으로 선택하며, 시장별 거래 시간과 주문 유형은 공식 문서에서 확인하세요.
  • 게만아 포스팅 시점에는 키움이 REST API 이용 매매에 수수료 혜택을 안내했습니다. 현재 조건은 키움증권 공지를 확인하세요.
  • API Key·Secret·접근 토큰은 비밀번호와 같습니다. 노출됐다면 폐기 후 재발급하세요.

자주 묻는 질문

키움증권 REST API와 기존 OpenAPI+(OCX 방식)는 무엇이 다른가요?

REST API는 HTTP 요청으로 호출하는 방식이라 별도 OCX 설치 없이 Windows뿐 아니라 macOS·Linux·AWS 서버에서도 파이썬으로 쓰기 쉽습니다. 예전 증권사 API는 윈도우 프로그램·ActiveX·COM 방식에 묶이는 경우가 많았습니다.

키움증권 API 사용신청은 어디에서 하나요?

키움 REST API 사이트의 우측 상단 [API 사용신청] 메뉴에서 진행합니다. 계좌가 있어야 신청할 수 있고, 승인 후 앱키와 앱시크릿을 발급받습니다.

키움증권 API는 왜 IP를 등록해야 하나요?

허용된 환경에서만 API를 호출하게 하는 보안 설정입니다. 게만아 구현 기준으로 한국투자·LS·DB증권과 달리 키움은 IP 등록이 필요했습니다. 내 PC의 IP와 자동매매 서버의 IP를 등록하고, IP가 바뀌면 다시 등록해야 합니다.

키움증권 모의투자로 먼저 테스트할 수 있나요?

가능합니다. 모의투자 전용 도메인이 있고, 설정 파일의 VIRTUAL 항목에 모의 계좌용 키를 넣어 accountMode를 "VIRTUAL"로 바꾸면 됩니다.

키움증권 API로 미국주식도 자동매매할 수 있나요?

가능합니다. 키움 REST API가 미국주식을 지원하고, 게만아 공통모듈도 국내(KR)와 미국(US) Helper를 제공합니다. 설정 값 Market으로 선택합니다. 다만 구현 초기(2025년 11월 포스팅)에는 해외주식 API가 없어 국내주식만 제공했으므로, 예전 포스팅의 “미국 미지원” 설명은 현재와 다릅니다.

키움증권 계좌 여러 개를 자동매매하려면 어떻게 하나요?

설정 파일에 REAL, REAL2, REAL3…처럼 계좌 항목을 추가하고, 봇의 accountMode 값을 바꾸면 됩니다. 계좌마다 토큰 저장 경로가 달라야 합니다.

근거와 확인 시점

이 페이지는 게만아의 키움증권 공통모듈 구현 포스팅(2025-11-17 게시)에서 직접 구현·운용하며 확인한 내용을 정리한 것입니다. 이후 추가된 미국주식 지원은 위 표와 FAQ에 반영했으며, 그 밖에 변경된 사양은 반영되지 않았을 수 있습니다. API 사양과 정책은 바뀔 수 있으므로 키 발급과 실제 주문 전에 공식 문서의 최신 내용을 확인하세요.
