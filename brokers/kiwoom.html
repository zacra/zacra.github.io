키움증권 REST API 파이썬 자동매매 가이드

키움증권 REST API는 별도 OCX 설치 없이 REST 기반으로 국내주식과 미국주식 기능을 제공하고 OAuth 인증과 WebSocket 실시간 기능을 함께 제공합니다.

공식 문서에서 확인할 핵심

  • 공식 안내에서 Windows뿐 아니라 macOS·Linux 등 멀티 OS 환경을 지원하는 REST API 구조를 설명합니다.
  • OAuth 접근토큰 발급 후 Bearer 토큰을 이용해 API를 호출합니다.
  • 국내주식 주문에서는 KRX·NXT·SOR처럼 거래소 구분이 필요한 경우가 있어 주문 파라미터를 확인해야 합니다.
  • 허용 IP 기반 보안 설정이 적용될 수 있으므로 서버 이전이나 공인 IP 변경 시 확인해야 합니다.

게만아 Starter에서의 위치

무료 Starter에서 해당 증권사 버전을 선택하면 국내주식 기준으로 계좌 조회·보유종목·리밸런싱·주문 흐름을 확인할 수 있습니다.

Starter는 전체 흐름을 이해하기 위한 Lite 예제입니다. 세부 주문유형·호출 제한·거래시간·지원 시장은 최신 공식 문서를 다시 확인하세요.
