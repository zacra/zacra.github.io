한국투자증권 KIS Open API 파이썬 자동매매 가이드

한국투자증권 Open API(KIS Developers)는 게만아 포스팅 기준 국내 증권사 가운데 가장 먼저 REST API를 제공한 곳으로, 국내·미국주식과 연금계좌까지 파이썬으로 자동매매할 수 있습니다. 앱키·시크릿으로 접근토큰을 발급하고, 계좌번호와 상품코드 2자리(일반계좌 01, 연금계좌 22 등)로 계좌를 지정합니다.

게만아 한국투자증권 공통모듈 대표 포스팅

게만아 한국투자증권 공통모듈(패키지 78번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 한국투자증권 계좌를 준비합니다. 연금계좌도 같은 방식으로 지정할 수 있습니다.
  2. KIS Developers에서 앱키·시크릿을 발급받습니다. 모의계좌는 별도로 발급합니다.
  3. 설정 파일에 앱키·시크릿·토큰 저장 경로와 계좌번호·상품코드 2자리를 넣습니다.
  4. 접근토큰을 발급해 저장해 두고 재사용하며, 만료 전에 주기적으로 갱신합니다.
  5. 조회부터 테스트합니다(잔고 → 보유종목 → 현재가).
  6. 주문은 마지막에, 가장 작은 수량으로 확인합니다.

게만아 공통모듈로 쓰면

게만아 주식 봇은 한국투자증권을 기본값으로 작성돼 있고, 다른 증권사로 바꿀 때 증권사 설정만 바꿉니다. 한국투자증권 공통모듈도 다른 증권사와 같은 함수 규격이며, 설정 파일의 계좌 항목(REAL·REAL2…·VIRTUAL)을 accountMode로 선택합니다.

Broker = "KIS"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2·VIRTUAL 등)

잔고 GetBalance · 보유종목 GetMyStockList · 현재가 GetCurrentPrice · 시장가·지정가 주문 · 주문 조회 등 (다른 증권사 공통모듈과 같은 규격)

실전에서 주의할 점

  • 상품코드를 정확히 넣어야 합니다. 일반계좌(01)와 연금계좌(22)처럼 계좌 종류마다 코드가 다릅니다.
  • 토큰은 저장해서 재사용하고 만료 전에 갱신하세요. 매번 새로 발급하는 구성은 오류와 제한의 원인이 될 수 있습니다.
  • 분봉 데이터에는 제약이 있습니다. 과거 분봉은 가져올 수 없고 당일 분봉만 제한된 개수씩 받을 수 있으니, 분봉 전략은 이를 감안해 설계하세요.
  • 다계좌는 토큰 저장 경로를 계좌마다 다르게 두세요.
  • 호출 제한과 정책은 공식 공지에서 확인하세요. API Key·Secret·토큰은 비밀번호와 같으니 노출되지 않게 하세요.

자주 묻는 질문

한국투자증권 API 앱키는 어디에서 발급하나요?

한국투자증권 Open API 포털인 KIS Developers에서 발급합니다. 실전용과 모의계좌용 키를 따로 받으며, 화면 구성은 바뀔 수 있으니 공식 포털의 최신 안내를 따르세요.

한국투자증권 API 계좌번호와 상품코드는 무엇인가요?

계좌번호와 함께 계좌 상품코드 2자리를 지정합니다. 일반계좌는 01, 연금계좌는 22 같은 코드를 씁니다. 다른 증권사와 달리 둘 다 필요합니다.

한국투자증권 API는 허용 IP를 등록해야 하나요?

아니요. 한국투자증권 API는 IP를 따로 등록하지 않고 사용합니다. 허용 IP 등록이 필요한 증권사는 토스증권과 키움증권입니다. 토스증권 가이드 → · 키움증권 가이드 →

한국투자증권 API로 미국주식과 연금계좌도 자동매매할 수 있나요?

가능합니다. 한국투자증권 REST API로 국내주식과 미국주식, 연금계좌까지 자동매매할 수 있다고 게만아 포스팅에서 설명합니다. 지원 범위는 계좌 종류와 주문 유형마다 다를 수 있습니다.

한국투자증권 API로 과거 분봉 데이터를 가져올 수 있나요?

게만아가 구현 당시(2024년 9월) 확인한 바로는 당일 1분봉만 한 번에 최근 30건씩 제공되고 과거 분봉은 제공되지 않았습니다. 필요한 N분봉은 당일 1분봉을 가공해 만듭니다. 현재 제공 범위는 공식 문서에서 확인하세요.

한국투자증권 접근토큰은 어떻게 관리하나요?

발급한 접근토큰을 파일 등에 저장해 재사용하고, 만료 전에 주기적으로 갱신하는 방식이 안전합니다. 게만아 강의는 토큰 저장 시스템과 스케줄러로 이를 구성하고, 패키지 78번은 다른 증권사와 같은 설정 파일 구조로 제공합니다.

한국투자증권 계좌 여러 개를 자동매매하려면 어떻게 하나요?

설정 파일에 REAL, REAL2, REAL3…처럼 계좌 항목(앱키·시크릿·토큰 경로·계좌번호·상품코드)을 추가하고, 봇의 accountMode 값을 바꿉니다. 토큰 저장 경로는 계좌마다 달라야 합니다.

근거와 확인 시점

이 페이지는 게만아의 한국투자증권 공통모듈 포스팅(2025-12-04 게시)과 분봉 조회 포스팅(2024-09-04 게시)에서 직접 구현·운용하며 확인한 내용을 정리한 것입니다. 이후 변경된 사양은 반영되지 않았을 수 있습니다. API 사양과 정책은 바뀔 수 있으므로 키 발급과 실제 주문 전에 공식 문서의 최신 내용을 확인하세요.
