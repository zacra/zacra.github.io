메리츠증권 Open API 파이썬 자동매매 가이드

메리츠증권 Open API는 REST 방식으로 제공되며 현재 베타 서비스입니다. 파이썬 자동매매 연동은 ① 메리츠증권 계좌 → ② API 신청 → ③ App Key·App Secret 발급 → ④ 설정 파일(yaml)에 입력 → ⑤ 테스트 파일로 조회 확인 순서입니다. 게만아 공통모듈은 국내·미국주식을 모두 지원하며, 다른 증권사와 달리 모의투자가 없어 앱키가 곧 실계좌라는 점을 꼭 기억하세요.

게만아 메리츠증권 공통모듈 대표 포스팅

게만아 메리츠증권 공통모듈(패키지 103번)의 준비 과정과 설정·사용 방법은 게만아 블로그의 대표 포스팅에서 설명합니다. 실제로 자동매매를 연결할 때는 이 포스팅을 먼저 읽어 주세요.

파이썬 자동매매 연동 순서

  1. 메리츠증권 계좌를 준비합니다.
  2. 개발자 포털 또는 메리츠 SMART 앱에서 Open API를 신청합니다.
  3. 신청 후 App Key와 App Secret을 잘 복사해 둡니다.
  4. myMR_StockInfo.yaml을 열어 REAL_APP_KEY, REAL_APP_SECRET에 입력하고 저장합니다.
  5. MR_KR_Test.py, MR_US_Test.py로 조회부터 확인합니다.
  6. 자동매매 봇의 Broker를 "MR", accountMode를 "REAL"로 바꾼 뒤, 모의투자가 없으므로 주문은 가장 작은 수량으로 먼저 확인합니다.

설정 파일(myMR_StockInfo.yaml)은 이렇게 채웁니다

발급받은 App Key·App Secret을 아래 REAL 항목에 넣고 저장하면 설정이 끝납니다. 메리츠 Open API는 현재 베타이며 모의계좌가 없어 앱키가 곧 실계좌입니다.

# 실계좌 정보 (메리츠 Open API는 베타이며 모의계좌 없음, 앱키 = 실계좌)
REAL_APP_KEY: "여러분의 앱키"
REAL_APP_SECRET: "여러분의 앱시크릿"
REAL_TOKEN_PATH: './mr_real_token.json'
REAL_URL: 'https://openapi.imeritz.com:9443'

# 계좌를 하나 더 쓰려면 같은 형식으로 REAL2를 채웁니다
REAL2_APP_KEY: ""
REAL2_APP_SECRET: ""
REAL2_TOKEN_PATH: './mr_real_token2.json'
REAL2_URL: 'https://openapi.imeritz.com:9443'

계좌가 3개라면 REAL3_… 항목을 같은 방식으로 추가합니다. TOKEN_PATH의 json 파일명만 계좌마다 달라야 합니다. VIRTUAL 항목은 다른 증권사와 파일 형식을 맞추기 위한 호환용이므로 사용하지 않습니다.

게만아 공통모듈로 쓰면

메리츠증권 공통모듈도 다른 증권사와 같은 파일 구조(_Common, _API_Helper_KR, _API_Helper_US, _StockInfo.yaml)로 만들었습니다. 그래서 패키지의 주식 자동매매 봇은 코드 상단의 증권사 설정만 바꿔 메리츠증권 계좌에서 운용할 수 있습니다. 계좌가 여러 개라면 accountMode를 "REAL" ↔ "REAL2" ↔ "REAL3"처럼 바꾸면 됩니다.

Broker = "MR"        # 증권사 선택(KIS / DBI / LS / KIW / TOSS / KB / NH / MR)
Market = "KR"          # KR=국내주식 / US=미국주식 (봇마다 지원 시장이 다르니 봇 주석을 따르세요)
accountMode = "REAL"    # yaml 설정의 계좌명(REAL·REAL2·REAL3 등)

다른 증권사 공통모듈과 같은 구조라서 같은 봇을 증권사만 바꿔 쓸 수 있습니다. 한국투자·LS·키움·토스·KB·NH증권을 쓰던 봇도 Broker 값만 바꾸면 메리츠증권으로 옮길 수 있습니다.

실전에서 주의할 점

  • 모의투자가 없습니다. 모든 테스트가 실계좌에서 이뤄지므로 조회(잔고·현재가)부터 확인하고, 주문은 마지막에 가장 작은 수량으로 해보세요.
  • 베타 서비스입니다. 사양과 정책이 바뀔 수 있으니 개발자 포털의 공지를 가끔 확인하세요.
  • 계좌를 여러 개 쓸 때 토큰 파일 경로가 겹치면 안 됩니다. REAL과 REAL2의 TOKEN_PATH 파일명은 서로 달라야 합니다.
  • 봇의 Market 설정을 함부로 바꾸지 마세요. 국내상장 전용으로 만든 봇은 시장을 바꾸면 봇 이름과 주문 시장이 어긋날 수 있습니다. 봇 코드 상단의 주석을 따르세요.
  • App Key·App Secret·토큰 파일은 비밀번호와 같습니다. myMR_StockInfo.yaml을 다른 사람과 공유하거나 공개 저장소에 올리지 마세요. 노출됐다면 폐기 후 재발급하세요.
  • 설정이 잘 안 되는 부분은 게만아 지원 카페에서 문의할 수 있습니다.

자주 묻는 질문

메리츠증권도 Open API를 제공하나요?

네. 메리츠증권이 REST 방식의 Open API를 제공하기 시작했고, 현재는 베타 서비스 기간입니다. 게만아는 조회와 매매가 정상 동작하는 것을 확인해 공통모듈을 패키지 103번으로 추가했습니다.

메리츠증권 API 신청은 어디에서 하나요?

개발자 포털의 API 신청 페이지(openapi.imeritz.com/api-apply)에서 할 수 있고, 메리츠증권 앱(메리츠 SMART)에서 “API”를 검색해도 메뉴가 나와 쉽게 신청할 수 있습니다. 신청 후 App Key와 App Secret을 복사해 설정 파일에 넣습니다.

메리츠증권 API는 IP를 등록해야 하나요?

게만아 구현 기준으로 별도 IP 등록 없이 사용합니다. IP 등록이 필요한 곳은 토스증권과 키움증권입니다.

메리츠증권 API로 모의투자를 먼저 해볼 수 있나요?

아니요. 베타 기간에는 모의계좌가 제공되지 않습니다. 앱키가 곧 실계좌이므로 조회부터 확인하고, 주문은 가장 작은 수량으로 시작하세요.

메리츠증권 API로 미국주식도 자동매매할 수 있나요?

게만아 공통모듈은 국내(KR)와 미국(US) Helper를 모두 제공합니다. 연결 확인용 테스트 파일도 MR_KR_Test.py와 MR_US_Test.py로 나뉘어 있습니다.

메리츠증권 계좌를 여러 개 자동매매하려면 어떻게 하나요?

계좌마다 App Key를 따로 발급받아 설정 파일의 REAL, REAL2, REAL3 항목에 순서대로 넣고, 봇의 accountMode를 바꾸면 됩니다. 토큰 파일 이름은 계좌마다 달라야 합니다.

다른 증권사에서 쓰던 자동매매 봇을 메리츠증권으로 바꾸려면?

봇 코드 상단의 Broker를 "MR"로, accountMode를 "REAL"(두 번째 계좌는 "REAL2")로 바꾸면 됩니다. 공통모듈이 같은 구조로 만들어져 있어 전략 코드는 그대로 씁니다. 다만 봇마다 지원 시장이 다르니 봇 코드의 안내 주석은 확인하세요.
