무료 파이썬 주식 자동매매 Starter

AutobotEx Starter는 국내주식 자동매매를 처음 접하는 사람이 전략 → 투자비중 → 백테스트 → 증권사 Open API → 실제 계좌 리밸런싱 → 주문 구조를 한 번에 경험하는 입문용 Lite 시스템입니다.

Starter의 목적은 ‘수익률 높은 전략 하나’를 주는 것이 아닙니다

전략을 정하고 → 과거 데이터로 검증하고 → 목표 비중을 계산하고 → 실제 계좌와 연결해 → 정해진 기준대로 실행하는 시스템 투자의 전체 흐름을 직접 경험하는 것이 목적입니다.

게만아 전체 콘텐츠와 Starter의 관계

게만아는 주식·ETF뿐 아니라 코인 자동매매, 백테스트, 여러 API와 시스템 투자 전반을 다룹니다. Starter는 그중 국내주식 + 1개 증권사 + 1개 자산배분 예시에 초점을 맞춘 무료 입문판입니다.

Starter는 정식 공통모듈의 ‘전체판’이 아닙니다

Starter의 목적은 증권사 Open API의 모든 기능을 제공하는 것이 아니라, 파이썬 자동매매의 핵심 흐름을 실제로 한 번 연결해보는 것입니다.

그래서 인증, 계좌·보유종목·현재가 조회, 기본 시세 데이터, 리밸런싱 계산, 시장가 주문처럼 입문과 기본 매매에 필요한 기능을 중심으로 공개합니다.

게만아 패키지나 슈퍼 이동평균에서 사용하는 정식 증권사 공통모듈은 Starter보다 기능이 더 많이 구현되어 있습니다. 정식 모듈 역시 증권사 API 전체를 복제한 범용 SDK가 아니라, 실제 전략과 시스템에서 필요해 사용해온 기능 중심으로 구성됩니다.

무료 Starter에서 할 수 있는 것

  • 정적 자산배분 예시 이해
  • 효율적 투자선으로 과거 데이터 기반 비중 후보 계산
  • 동일비중과 자동 계산 비중의 백테스트 비교
  • 증권사 Open API 인증과 계좌·보유종목·현재가 조회
  • 목표비중과 현재비중의 차이로 리밸런싱 수량 계산
  • 실제 시장가 주문 구조 확인

현재 지원 증권사

한국투자증권, LS증권, 키움증권, 토스증권, KB증권, NH투자증권, DB증권 중 한 곳을 선택합니다. 지원사가 늘어나더라도 전체 구조는 같은 방향으로 확장할 수 있습니다.

과거 데이터 기반 비중은 미래 최적 비중이 아닙니다

Efficient Frontier 결과는 과거 수익률·변동성·상관관계를 이용한 후보입니다. 미래 성과를 보장하지 않습니다.

실제 주문 전 확인

처음부터 주문을 활성화하지 말고 조회·계산 결과를 먼저 검증합니다. 실제 주문 전에는 계좌, 종목, 수량, 거래시간, 거래소 구분, 수수료·세금을 직접 확인하세요.

Starter에서 더 확장하고 싶다면

Starter는 자동매매의 전체 흐름을 경험하기 위한 Lite 코드입니다. 정식 콘텐츠에는 실제 전략 운용에 사용하는 기능이 더 넓게 구현되어 있으므로, 처음부터 증권사 API 문서를 보고 필요한 기능을 직접 채워 넣어야 하는 구조는 아닙니다.

전략 조건을 바꾸거나, 백테스트를 확장하거나, 자동매매 봇·알림·공통모듈을 자신의 방식으로 수정하고 싶다면 기존 코드를 AI에게 읽혀 필요한 부분부터 확장할 수 있습니다. 새로운 API 기능 자체가 필요할 때만 공식 API 문서를 참고하면 됩니다.
