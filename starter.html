무료 파이썬 주식 자동매매 Starter

AutobotEx Starter는 국내주식 자동매매를 처음 접하는 사람이 전략 → 투자비중 → 백테스트 → 증권사 Open API → 실제 계좌 리밸런싱 → 주문 구조를 한 번에 경험하는 입문용 Lite 시스템입니다.

Starter의 목적은 ‘수익률 높은 전략 하나’를 주는 것이 아닙니다

전략을 정하고 → 과거 데이터로 검증하고 → 목표 비중을 계산하고 → 실제 계좌와 연결해 → 정해진 기준대로 실행하는 시스템 투자의 전체 흐름을 직접 경험하는 것이 목적입니다.

게만아 전체 콘텐츠와 Starter의 관계

게만아는 주식·ETF뿐 아니라 코인 자동매매, 백테스트, 여러 API와 시스템 투자 전반을 다룹니다. Starter는 그중 국내주식 + 1개 증권사 + 1개 자산배분 예시에 초점을 맞춘 무료 입문판입니다.

무료 Starter에서 할 수 있는 것

  • 정적 자산배분 예시 이해
  • 효율적 투자선으로 과거 데이터 기반 비중 후보 계산
  • 동일비중과 자동 계산 비중의 백테스트 비교
  • 증권사 Open API 인증과 계좌·보유종목·현재가 조회
  • 목표비중과 현재비중의 차이로 리밸런싱 수량 계산
  • 실제 시장가 주문 구조 확인

지원 증권사

한국투자증권, LS증권, 키움증권, 토스증권, KB증권, NH투자증권, DB증권 중 한 곳을 선택합니다.

과거 데이터 기반 비중은 미래 최적 비중이 아닙니다

Efficient Frontier 결과는 과거 수익률·변동성·상관관계를 이용한 후보입니다. 미래 성과를 보장하지 않습니다.

실제 주문 전 확인

처음부터 주문을 활성화하지 말고 조회·계산 결과를 먼저 검증합니다. 실제 주문 전에는 계좌, 종목, 수량, 거래시간, 거래소 구분, 수수료·세금을 직접 확인하세요.

전체 설치·신청·실행 가이드

실제 파일 배포와 설치 순서는 게만아 네이버 블로그의 Starter 랜딩에서 안내합니다.
